## Key Discoveries

- 个人注册小程序不收费。上线前要做小程序备案，备案本身不收费。企业微信认证 300 元一次，按年审。个人认证口径不一致：开放文档仍写个人暂不支持认证；腾讯客服有个人流程，社区近期说法是 30 元一次。只给自己用、不接微信支付，可以先不认证。
- 持续费用是服务器或云开发套餐，加上 Mimo 调用。微信云开发：2025-02-19 起符合条件的小程序可建一个免费环境，未发布时不用续费；发布后免费环境到上线第 15 天到期，要长期用需转付费。价格页上的基础套餐约 19.9 元/月，活动到 2026-12-31。云函数超时在旧说明里上限约 20 秒，长的 Mimo 分析可能放不进一次调用。
- 安卓书架在手机 `filesDir/shelf`，词典从 assets 拷贝 `ecdict.db`。
