## Goal & Scope

手机精读里，每一页生成过的好词好句和社会文化要留下来。再打开这一页，点对应按钮先看到已保存的内容。有保存时可以重写，覆盖这一种。存在这台手机上，跟这本书放在一起，不传到电脑 Jarvis。

## Key Decisions

1. **两种分开存，点按钮先看已保存的**（2026-10-15）：好词好句和社会文化各记各的。再点同一个按钮，有内容就显示，不再请求。没有内容才生成。
2. **重写只覆盖当前这一种**：另一种不动。生成完整结束才写入。中途取消留下的半截不覆盖已经保存的。
3. **不进入 brainstorming，按确认的理解直接做**。用户要求把理解写入本文件。
4. **存在书架目录里单独的分析文件，不写进正文文件**：重切会换掉页的边界，所以重切时删掉这本书的分析。删书时一起删。文件损坏时不覆盖。Rejected: 把分析塞进正文 JSON，每次保存都重写整本书。
5. **复查后只补测试**（2026-10-15）：正文文件在保存分析后保持原样。只有生成完成、没有错误、正文不是空白才写入。重切当下分析文件就不在了。取消后屏幕仍可能留下半截、要再点一次才看到旧文，这条先不改。
6. **补测试的复查没有新问题**（2026-10-15）：正文文件、重切删分析、取消或失败不写入，都有测试，而且生成结束走的是同一条判断。
