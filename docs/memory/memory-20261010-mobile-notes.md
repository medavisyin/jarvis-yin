## Goal & Scope

在 Android 精读里加只存在这台手机上的笔记。书架旁边有「笔记」入口。分析段、选区、以及点「词」或「句」之后的窗口，都可以一点保存书名和高亮文字。列表收起只显示书名，点开才显示全文，可以删除，展开后可以分享。不能编辑。不连电脑上的 My Notes。

## Key Decisions

1. **只存在手机上**：不调用电脑 `POST /api/notes`。Rejected: 同步到 Jarvis；先存手机以后再同步。
2. **一点保存，不用打字**：分析段记书名加这一段。选中文字记书名加高亮范围，不记中文释义。Rejected: 弹出输入框；保存后再改删。
3. **一个 notes.json，和书架并列**：最新的在上面。Rejected: 每本书单独一份；用数据库。
4. **入口在书架旁边**，列表空时显示「还没有笔记」。
5. **直接实现，不另写计划**。用户要求把设计写入本记忆文件。
6. **接受 Important-1 和 Minor-1**：损坏的 `notes.json` 再保存时不覆盖原文件。从书里打开笔记时不显示页码和「章节」。用户要求两条都改。复查认为这两条已满足。
7. **Deferred: 复查 Minor-1**：`NoteStore.write` 在原子替换失败时用 `copyTo(overwrite = true)`，会先删目标再拷贝。用户选择先不改（2026-10-10）。这条不在损坏文件的路径上。
8. **Reversed: 这一轮不能删除**：用户要求笔记列表像电脑端，可以删除。收起只显示书名，点开才显示全文，同一时间只展开一条。展开后出现「删除」，点了立刻删除，不再确认。文件损坏时删除不改文件。仍然不能编辑。
9. **解释窗口里的笔记**：点「词」或「句」后的窗口底部加「笔记」。保存书名和当前高亮（`WordHit.word`），不保存整句、词典释义、中文解释。保存后窗口不关。选区上的「笔记」保留，保存内容相同。Rejected: 窗口里保存词典和中文解释；句的窗口保存整句；删除前再确认一次。
10. **展开后分享**：用户确认在「删除」旁边加「分享」。系统分享，正文用 `AnalysisShare.body`（书名、换行、笔记全文）。点分享不收起这条。收起时仍只显示书名。不能编辑。做法已确认，代码还没写（2026-10-10）。
11. **接受 Important-1，还没改完**：解释窗口不滚动，「笔记」在长词典卡片底部会被挤出屏幕。用户要求改：正文可滚动，按钮留在可见区域。半截测试已撤掉，代码未改。
12. **Reversed: 每一行一本书**（2026-10-10）：列表不再把同一书名重复多行。一行一个书名。点开弹出这份书的选取列表，每一条的标题是选取的文字。再点一条才展开全文、分享和删除。同一时间只展开一条。用户要求直接改，不再确认。
13. **展开后要有解释**（2026-10-11）：只看单词没有意义。点开一条后，分享和删除上面显示词典释义，以及当时已经写好的中文解释或句子翻译。还在「正在…」的解释不存。点「句」之后记的是这一句，不是单词。以前没有解释的旧笔记仍只有选取文字。
14. **解释复查没有新问题**（2026-10-11）：「正在…」不会存进笔记。展开后解释在分享和删除上面。点「句」记的是句子。旧笔记没有解释字段也能打开。
15. **三层要能分开看**（2026-10-11）：书名是带左边线和条数的卡片。点开后选取是另一层圆角块。再点开，解释单独一块，分享和删除在右下。沿用阅读页的纸色和衬线。
16. **Reversed: 解释窗口把「笔记」钉在可见区域**（2026-10-11）：和阅读体验一起改。窗口最高约屏幕八成，词典和「笔记」在同一条滚动里，「笔记」在最下面。保存内容不变。详见 `docs/memory/memory-20261011-reading-comfort.md`。
