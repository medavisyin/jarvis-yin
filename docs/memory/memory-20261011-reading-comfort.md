## Goal & Scope

1. **七条都做**（2026-10-11）：栏目小字、书架已读篇数、藏刊头、书架章内页、左右缘翻页、章首页放大章名、解释窗口可滚动。
2. **打开时现算，不改书里的文字**。书架画出来时读每本书的页和已读。Rejected: 离开阅读时把书架那一行写进索引；Rejected: 改导入，只让新书变干净。
3. **杂志顶栏**：书名下面一行小字栏目，再下面是篇名。一篇只有一页也显示篇名。正文第一行如果就是栏目名，显示时跳过。
4. **刊头只藏开头**：日期加 PRICE、整行是刊头（The Economist、2024 PRICE、封面、目录），以及行首的日期价格。文章中间的 PRICE 不动。藏完如果变空，仍显示原文。
5. **小说章名**：只在一章的第一页放大。正文第一行就是章名时，只把这一行放大。后面的页仍用顶栏「章名 · 2/5」。
6. **左右缘只给小说**：点左边上一页，点右边下一页。横滑还在。中间长按选词。已经选中词时，点边缘仍翻页。杂志不加点边翻页。
7. **书架杂志写「已读 4 篇」**：同一篇的前后页只算一篇。不再写「上次读到 12/80」。零篇也写「已读 0 篇」。
8. **书架小说**：当前页有章名时写「Chapter 3 · 2/5」，一章只有一页时只写章名。没有章名的书仍写「上次读到 12/80」。
9. **解释窗口**：最高大约占屏幕八成，词典和「笔记」在同一条滚动里，「笔记」在最下面。保存的内容不变。这改掉笔记记忆里「按钮留在可见区域、还没做」的那条：按钮跟着正文滚，不再钉在窗口上。
10. **直接做，不另写计划**。用户要求把设计写入本记忆文件。
11. **复查后只改 Important-1 和 Important-2**（2026-10-11）：左右缘不再盖住正文。点正文左右 56dp 才翻页，长按仍选词，「词」按钮在正文上面。测试补上开头才藏刊头，以及整行 The New Yorker、Wired、2024 PRICE、Cover、Contents、Masthead。Minor-1（`$1,200` 会被截成 `,200`）和 Minor-2（连点边缘只翻一页）先不改。
