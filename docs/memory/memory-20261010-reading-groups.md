## Goal & Scope

手机精读里，经济学人要按栏目读、看出一篇的后半、记下这期读过哪些。小说要看出章内第几页，并能把整句存进笔记。已导入的经济学人不重切、不重新导入。

---

## Key Decisions

1. **已导入的经济学人不重切**：书架上已有篇名和正文。栏名留在正文里，长文篇名已有 `(1)`、`(2)`。按栏目、1/2、已读都从这些数据来。Rejected: 点「重切」；Rejected: 为这四件事重新导入。只有某一栏的栏名在保存时整段丢掉，才从「经济学人」入口重新导入那一期。
2. **读完是翻到最后一页**：一篇的最后一页成为当前页时，这篇算读完。翻页旁边另有「下一篇」，跳到下一篇第一页。Rejected: 篇末按钮一次完成标记并跳转；Rejected: 在菜单里勾选。
3. **这些只在能认出栏目的书上出现**：章节菜单按栏目分组，已读有标记。认不出栏目的书（普通小说）不标已读、没有「下一篇」。
4. **小说章内页码**：有章名时，菜单和页脚写「章名 · 2/5」，用已保存的章名，不改成「第三章」。没有章名的旧书仍是「第 N 段」，要章内页码就先点「重切」。
5. **摘句在选词条**：放在「笔记」旁边，存这一句，标题是书名。解释窗口的「笔记」仍只存划中的词。书架分不出经济学人和小说，所以摘句两边都会出现。Rejected: 只放在「句」的窗口里；Rejected: 两处都放。
6. **不隐藏「重切」**：每本书仍有这个按钮。经济学人点了会提示「没有找到章节」，正文不动。
7. **打开时现算，已读另存**（2026-10-10，设计已通过，直接实现）：不把栏目和 1/2 写回篇名。至少两个不同栏目才当成经济学人。栏名只看篇名和正文前三行。长文把 `(1)`、`(2)` 收成「篇名 · 1/2」。已读记「栏目 + 篇名」，写在这本书的文件里，重切不靠页码。当前页是一篇的最后一页才标已读。顶栏有「下一篇」。小说连续相同章名显示「章名 · 2/5」，菜单和顶栏都有。摘句在选词条「笔记」右边。Rejected: 第一次打开就改写篇名；Rejected: 已读只记页码。
8. **复查只改两条 Important**（2026-10-10）：已读先写入临时文件再换名，不把正在读的正文截断。篇内位置放进书名那一格，随书名缩短；「下一篇」固定宽度。Minor-1 到 Minor-4 先不改。
9. **这两处复查没有新问题**（2026-10-10）：已读换名失败时原文还在。篇内位置在书名下缩短，「下一篇」和页码都在。四条 Minor 仍先不改。已覆盖安装到 GRL-AL10。

## Confirmed Assumptions

- 单页文章一停在那一页就算读完。
- 同一篇的 `(1)`、`(2)` 显示成 1/2、2/2，不改已存正文。
- 栏目从已存正文按顺序认，看到栏名就归到这一栏，直到下一个栏名。

## Constraints & Non-Goals

- 不改切页，不调用 `BookChapters.retitle` 来做经济学人。
- 不改解释窗口「笔记」的存词行为。
- 不给经济学人单独隐藏「重切」。

## Key Discoveries

- `MagazineChunker.splitOversized` 把超长文章切成同一篇名加 ` (1)`、` (2)`。栏名（Leaders、Britain 等）在切分时认过，并留在对应正文里。书架 JSON 没有单独的栏目字段。
- 书架 `kind` 是 epub 或 pdf，经济学人和本地书无法区分。
- 小说章名存在每页 `titles` 里。同一章的多页标题相同。空标题菜单显示「第 N 段」。
