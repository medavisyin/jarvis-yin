# 优质低估选股（DeepSeek 策略说明 · 小白版）

**对应功能**：网页「💰 优质低估」  
**对应实现**：`scripts/stock/quality_value_scanner.py`  
**技术细节**：[quality_value_scanner.md](./quality_value_scanner.md)  
**最后更新**：2026-08-16

> ⚠️ **合规提示**：本文解释优质低估漏斗**如何从全市场筛到最多 5 只**，**不构成投资建议**。可以 0 只推荐（宁缺毋滥）。  
> 与「A股分析 / 左右推荐」的 DeepSeek **主尺子不同**：本功能是价值投资、持有口径约 **6 个月～2 年**；短线可买性请用推荐或单股分析（二者共用约 1～2 周人设）。也不要和「长期推荐」的新闻主题混用。

---

## 1. 这是干什么的

### 1.1 一句话

在 A 股里找**基本面还过得去、相对同行更便宜**的股票：同业 PE/PB 偏低、股息尚可、再过一遍财务排雷和 PB-ROE 排序，最后让 DeepSeek 看行业周期和价值陷阱。最多 **5 只**，尽量不同行业。

### 1.2 生活比喻

像在同一条街比较房租，而不是拿陆家嘴公寓去比县城平房：

- 先丢掉你买不了的铺面（创业板 300/301）和明显有问题的房东（ST / 退市）  
- 只和**同一业态**比贵贱（银行跟银行比，白酒跟白酒比）  
- 再看房东会不会一直亏、会不会债台高筑  
- 最后请一个懂行的人看：这条街是不是在走下坡路、便宜是不是「便宜有便宜的道理」

### 1.3 交易节奏 / 持有周期

- **时间框架**：约 **6 个月～2 年**（中长期价值配置）。  
- **不是** 1～2 周波段，也**不是**长期推荐那种「新闻主题 + 贵金属、约 3 个月～1 年」。  
- **宁缺毋滥**：当天没有同时满足优质+低估的票 → **0 只是功能，不是故障**。

### 1.4 在界面上怎么用

1. 工具栏点 **「优质低估」**  
2. **勾选 DeepSeek**（建议开：行业周期 / 价值陷阱 / 商誉终审）  
3. 开始扫描，等四步漏斗跑完  
4. 读报告：先看同业估值与 ROE，再看周期、陷阱、风险  
5. 需要纸质留存时点 **导出 PDF**

前提：全市场快照可用；行业映射读本地缓存（本扫描**不会**现场重建全部东财板块）。财务只拉 Layer1 入围（最多 100 只）。

## 2. 金融逻辑：为什么要这样交易

### 2.1 核心信念：同业相对低估 + 质量门槛

绝对 PE 没有意义：银行 PE 8 可能贵，软件 PE 25 可能便宜。本策略赌的是：

- **相对便宜**：同行业 PE、PB 低于行业均值  
- **质量还在**：ROE、三年利润增长、非金融负债率、扣非质量、分红稳定性  
- **价格相对盈利**：PB-ROE（ROE/PB）高的，同样净资产回报买得更便宜  
- **历史也不贵**：近 5 年 PE 分位不要处在自身高位（已知且 >30% 会踢）

### 2.2 金融股单独规则

银行 / 保险 / 证券等**资产负债率本来就高**。若全市场套「负债率 <60%」，会把银行扫光。

| 规则 | 非金融 | 金融 |
|---|---|---|
| 负债率 <60% | 硬门槛（缺数据也过不了） | **不考核** |
| PB&lt;1 | 只是便宜的一种形态 | **明确当作低估信号**记下 |
| ROE / 增长 | 要 | 要 |
| 股息过低（已知且 &lt;2.5%） | Layer1 已踢 | Layer2 再踢一次 |

### 2.3 A 股特殊点

- **创业板（300/301）第一步就排除**，且在算同业均值**之前**丢掉，避免把创业板的高估值/低估值扭曲主板同行均值。科创板 688/689 **保留**（账户能交易）。  
- ST / *ST / 退市整理剔除。  
- **规则层不筛商誉暴雷**（没有可靠的全市场商誉雷定量字段）；由 DeepSeek 在终审里看商誉/减值。  
- 缺分红、缺扣非、缺 5 年 PE 分位 → 标 `unknown`，**不自动淘汰**。

### 2.4 这套策略在赌什么优势

1. **同业尺子**：避免跨行业比 PE 的常识错误。  
2. **批量漏斗**：5000 只不逐只拉财报；只对相对便宜的前 100 只拉年报。  
3. **周期否决**：便宜遇到衰退行业，往往是价值陷阱。

## 3. 筛选漏斗（规则层先干活）

```
① 全市场快照（PE/PB/股息）+ 只读行业缓存
② Layer1：踢创业板、ST、PE≤0；同业 PE/PB 低于均值；已知股息 <2.5% 踢；按相对便宜排序，硬上限 100
③ 对入围股拉同花顺年报 + 分红（24h 缓存）
④ Layer2：ROE≥10、三年净利润 CAGR≥5%；非金融负债率<60%；扣非过低踢、未知保留；分红明确不稳踢
⑤ Layer3：PB-ROE 排序，每行业最多 2 只，取前约 20；再算近 5 年 PE 分位（已知>30 踢，未知保留）
⑥ DeepSeek 一次批量终审（JSON 数组）：周期衰退 / 价值陷阱 / 非买入 → 否决；最多 5 只
⑦ 落盘 Markdown / JSON / RAG / 可选 PDF
```

### 每层在干什么（大白话）

| 步骤 | 作用 |
|---|---|
| 快照 + 行业 | 回答“现在全市场贵贱长什么样” |
| Layer1 | 丢掉不能买的板、垃圾壳，只留相对同行便宜的 |
| 财报 | 给入围股补 ROE、增长、负债、扣非、分红 |
| Layer2 | 排雷：持续弱盈利、高负债（非金融）、扣非注水、分红断裂 |
| Layer3 | 同样便宜里，谁的盈利相对净资产更划算 |
| DeepSeek | 看周期、陷阱、商誉；宁缺毋滥裁到 ≤5 |

### “暂无推荐”正常吗？

**正常。** 例如：当天相对低估的票财务不过关、5 年分位都偏高、或 DeepSeek 认为全是衰退/陷阱。价值策略最怕的是“为了凑满 5 只而硬推”。

## 4. DeepSeek 在这里扮演什么角色

### 4.1 规则层 vs DeepSeek

| | 规则 / 数据层 | DeepSeek（勾选时优先） |
|---|---|---|
| 同业 PE/PB、股息、创业板/ST | ✅ | 不替代 |
| ROE / CAGR / 负债 / 扣非 / 分红 | ✅（缺则 unknown） | 不替代硬门槛 |
| 5 年 PE 分位 | ✅（缺则 unknown） | 参考 |
| 行业周期、价值陷阱、商誉减值 | 无定量筛 | **终审主笔** |
| 最终 ≤5 只 | 候选截断 | **一次批量 JSON 裁员** |

未开 DeepSeek 时：规则层 Top5 直接出报告，并标明「未经 AI 终审」。

**本功能不调用** `deepseek_shared_persona_rules()`（那是约 1～2 周短线人设）。

### 4.2 DeepSeek 会看到哪些信息

入围候选的代码、名称、行业、PE/PB/股息、ROE、PB-ROE、5 年 PE 分位、扣非状态等文本化列表。

### 4.3 它输出什么

一个 JSON **数组**（不是逐只连打 8～10 次）：

- `verdict`：买入 / 不买入  
- `score`、`cycle`（上升 / 平稳 / 衰退）、`trap`  
- `reason`、`risk`、`strategy`（6 个月～2 年持有纪律）  

规则再否决：非买入、`trap=true`、`cycle=衰退`。按分数取最多 5 只。

### 4.4 有没有二次复核硬门控？

- **有规则硬过滤**（板、ST、同业估值、财务门槛、分位）。  
- **没有**左侧那种 “Top5 深度看空否决” 的同一套机制；终审本身就是一次批量裁员。  
- **商誉不在规则层**，只在这一步定性。

## 5. 适合什么行情 / 不适合什么

| 更适合 | 不太适合 |
|---|---|
| 你想中长期配置「便宜且不太烂」的公司 | 你想今天下午买、一两周就走 |
| 愿意按行业比较估值 | 只看绝对低 PE、跨行业比谁更便宜 |
| 能接受 0 只、少只 | 每天必须凑满 5 只才安心 |
| 账户不能买创业板、需要系统先滤掉 | 主要交易 300/301 |

### 常见误用

- 把优质低估当短线买卖点。  
- 金融股因为负债率高就当垃圾（本策略已经放行负债，但仍看 ROE/股息）。  
- 忽略报告里的 **周期 / 价值陷阱 / 风险**。  
- 缺分红、缺扣非被标 unknown 时，当成「已经验证过」。

---

## 6. 报告怎么读（小白对照表）

| 内容 | 含义 | 怎么用 |
|---|---|---|
| 行业 + 同业 PE/PB 均值 | 相对同行贵贱 | 先确认不是跨行业误比 |
| PE / PB / 股息 | 当下估值与分红 | 股息缺失 = unknown，不是 0 |
| ROE / 三年增长 / 负债 | 质量与排雷 | 金融股负债高不必大惊小怪 |
| PB-ROE | 盈利相对净资产的性价比 | 越高通常越「便宜买到回报」 |
| 近 5 年 PE 分位 | 相对自己历史贵不贵 | 未知则别当成已经很低 |
| 周期 | 上升 / 平稳 / 衰退 | **衰退 → 再便宜也不该当配置** |
| 价值陷阱 / 商誉 | DeepSeek 定性 | **必读**；规则层没筛过 |
| 0 只 | 宁缺毋滥 | 不是系统坏了 |

---

## 7. 风险与纪律（必读）

1. **低估可以更低**：相对便宜不是立刻上涨。  
2. **价值陷阱**：盈利恶化、护城河消失时，低 PE 是诱饵。  
3. **周期**：衰退行业的「便宜」往往继续便宜。  
4. **数据缺口**：扣非、分红、历史分位经常缺失；unknown ≠ 安全。  
5. **仓位**：最多 5 只仍要分散；单票不梭哈。持有口径按半年到两年复盘，不要「改口变超短」。  
6. **合规**：筛选仅供参考，最终买卖与盈亏自负。

## 8. 和另外几套的区别

| | 优质低估 | 长期推荐 | 左右统一推荐 | 单股分析 | 午盘 T+1 |
|---|---|---|---|---|---|
| 驱动 | 同业低估 + 财务排雷 + PB-ROE | 新闻/政策/贵金属主题 | 价量+资金+截面/反转 | 你指定个股深挖 | 上午盘量价资金 |
| 周期 | 约 **6 个月～2 年** | 约 3 个月～1 年 | 约 1～2 周 | 约 1～2 周情景 | 隔夜 |
| DeepSeek | 独立价值人设（周期/陷阱/商誉） | 主题 + 终选 | 与深度分析同一短线人设 | 长研报 | 游资隔夜裁判 |
| 创业板 | **第一步排除** | 不按本漏斗滤板 | 另套规则 | 你指定什么就分析什么 | 另套规则 |
| 典型输出 | ≤5 只；可为 0 | 主题卡 + ≤5 股 | 左右列表 | 1 份深度报告 | 0～3 只极速内参 |
