# A股分析 & AI预测（DeepSeek 策略说明 · 小白版）

**对应功能**：网页 Stock →「A股分析 & AI预测」→ 勾选 DeepSeek 标签  
**对应实现**：`scripts/stock/llm_reasoning.py`（技术细节见 [llm_reasoning.md](./llm_reasoning.md)）  
**最后更新**：2026-08-05（§4.2 小白释义；§4.5 与推荐人设对齐说明）

> ⚠️ **合规提示**：本文只解释 Jarvis 在开启 DeepSeek 时**怎么分析一只股票**，**不构成任何投资建议**。股市有风险，买卖与盈亏由你自己负责。

---

## 1. 这是干什么的

### 1.1 一句话

给你**已经想好的一只股票**（比如茅台 600519），把技术面、基本面、新闻情绪、主力资金、机器学习预测等材料摊开，让 **DeepSeek 当“资深分析师”**，写出一份带概率、情景和操作建议的中文研判报告。

### 1.2 生活比喻

想象你要决定要不要买某套二手房：

| 信息来源 | 对应 Jarvis | 比喻 |
|---|---|---|
| 户型、楼层、学区 | 基本面（财务、估值） | 房子本身好不好 |
| 最近成交价、挂牌走势 | 技术面 + 近 20 日行情 | 市场最近怎么走 |
| 中介话术、小区八卦 | 新闻情绪 | 大家怎么说 |
| 附近大资金成交 | 主力资金流向 | 懂行的人在买还是在逃 |
| 房价模型粗估 | XGBoost / 价格预测模型 | 电脑算的“可能涨跌概率” |

**DeepSeek 的工作不是再去“找房”**，而是把这些材料对照着读，找出**互相打架的地方**和**互相印证的地方**，最后用概率告诉你：更像涨、跌还是震荡，以及不同仓位的人该怎么做。

### 1.3 交易节奏 / 持有周期

- **不是选股器**：不会从 5000 只里帮你挑；你要自己输入代码。
- **偏研究助理**：时间框架通常落在**未来 1～2 周**的情景，也会给关键价位与止损感。
- **和“推荐扫描”的区别**：推荐功能是“市场上有没有值得看的”；本功能是“这一只到底怎么看”。

### 1.4 在界面上怎么用

1. 打开 Stock 区域的 **「A股分析 & AI预测」**
2. 输入股票代码（如 `600519`）
3. 切到 **「DeepSeek」** 标签（或勾选 DeepSeek）
4. 确保设置里已配置 DeepSeek API Key
5. 开始分析，等待生成 `prediction-report-deepseek.md` 风格的长报告

> 💡 勾 DeepSeek 前，最好先让系统拉过该股的行情、技术分析、基本面与（若有）ML 预测；材料越全，报告越有料。材料缺失时，DeepSeek 仍可能写，但对应章节会空或变弱。

## 2. 金融逻辑：为什么要这样分析

### 2.1 核心信念（大白话）

**单一信号不可信，交叉验证才靠谱。**

- 技术面说“超卖要反弹”，但主力在出货 → 可能是假反弹。
- 基本面很好，但估值已经贵到离谱 → 好公司也可能买贵了要等。
- 新闻很热，但量价没有配合 → 可能是情绪泡沫。

DeepSeek 版策略强制模型做的事，正是：**找矛盾、找共振，用概率说话，而不是甩一句“建议买入”。**

### 2.2 A 股特殊规则怎么进入分析

| A 股现实 | 报告里为什么要提 |
|---|---|
| **T+1**（今天买了明天才能卖） | 追高被套当天出不来；建议要考虑隔夜风险 |
| **涨跌停板** | 涨停附近买容易买不到或次日溢价透支；跌停卖不掉 |
| **散户多、主力痕迹明显** | 要解读吸筹 / 拉升 / 出货，而不只看均线 |
| **情绪与政策敏感** | 新闻与大盘情绪不是装饰，而是风险输入 |

### 2.3 这套策略在赌什么“优势”

它赌的不是“AI 算得准明天收盘价”，而是：

1. **信息整合优势**：普通人很难同时盯住十几种数据；系统先帮你整理。
2. **对抗过度自信**：要求写概率与乐观/中性/悲观情景，减少“感觉一定会涨”。
3. **仓位差异化**：空仓、轻仓、重仓的人决策不同——同一份报告给三种建议。

> 记住：概率不是保证。70% 看涨仍有 30% 会错；错的时候要靠你自己的止损纪律。

## 3. 筛选漏斗（规则层先干活）

单股分析**没有全市场漏斗**，但有一套**“材料装配流水线”**：先机器收集，再交给 DeepSeek 写结论。

```
① 技术分析（均线/MACD/RSI/形态/支撑阻力等）
② 基本面（公司资料、财务、估值评分）
③ 新闻情绪（若有缓存或现场分析）
④ 可选：XGBoost 方向预测、次日价格预测 JSON
⑤ DeepSeek 额外材料：近 20 日 **OHLCV**（开/高/低/收/成交量）表、资金流向、大盘情绪
        ↓
⑥ DeepSeek 深度推理 → 结构化中文报告落盘
```

### 每一层在干什么

| 步骤 | 在筛/装什么 | 为什么 |
|---|---|---|
| 技术分析 | 价量结构、超买超卖、趋势 | 回答“现在贵不贵、动能强不强” |
| 基本面 | 赚钱能力与估值是否离谱 | 回答“公司底子如何” |
| 情绪 | 近期新闻偏多还是偏空 | 回答“市场在讲什么故事” |
| ML（可选） | 涨/平/跌概率、粗略价位 | 当作**参考天气**，不是圣旨 |
| 资金流向 | 主力净流入与阶段（布局/拉升/出货） | A 股特有的“聪明钱痕迹” |
| 大盘情绪 | 整体风险偏好 | 个股再强也怕系统性下跌 |

### “报告很空 / 很短”是怎么回事？

- 某类数据没拉到 → 对应章节弱或缺失（正常）。
- DeepSeek 偶发空回复时，系统会按策略重试；仍失败则报错，**不会假装写出完整报告**。
- **没有“暂无推荐”这回事**：因为你已经指定了股票；得到的是研判，不是买卖强制结论。

## 4. DeepSeek 在这里扮演什么角色

### 4.1 规则层 vs DeepSeek

| | 规则 / 传统模块 | DeepSeek |
|---|---|---|
| 职责 | 算指标、评分、装数据 | **交叉解读 + 叙事 + 概率化结论** |
| 会不会直接下单建议 | 给出信号与分数 | 给出方向、概率、三类仓位建议、止损感 |
| 能否替代你 | 否 | **否**——它是研究员，你是决策者 |

### 4.2 DeepSeek 会看到哪些信息（清单）

典型 DeepSeek 上下文包括（有则给、无则跳过）：

- 近 **20 个交易日** 的开高低收量（原始表，方便它自己看量价）
- **全套技术指标与信号摘要**（见下方 §4.2.1）
- **基本面与估值评分**（见下方 §4.2.2）
- 新闻列表（尽量全量，而不只是标题三两句）
- **XGBoost：方向、置信度、概率分布、重要特征**（若有；见下方 §4.2.3）
- 价格预测模型结果（若有）——另一套模型粗估「大概可能到什么价」，当作区间感，不是必达目标价
- **个股资金流向信号**（吸筹/出货等）
- **大盘情绪**快照
- （可选）你的成本价 → 额外给出持仓情景下的加减仓建议

#### 4.2.1 「全套技术指标与信号摘要」是什么？

可以把它想成：**用尺子量股价最近在干什么**，再贴上「偏多 / 偏空 / 中性」的标签，方便 DeepSeek 快速读盘，而不用你自己背公式。

| 白话概念 | 常见例子（Jarvis 里会算） | 你要记住的一句话 |
|---|---|---|
| **均线** | MA5、MA10、MA20… | 近几天/几周的「平均成本线」。价在线上偏强，线下偏弱 |
| **趋势/拐点** | MACD | 看涨跌动能有没有换挡；常说的金叉/死叉就在这类信号里 |
| **超买超卖** | RSI、KDJ | 涨得太疯可能「过热」，跌得太狠可能「超卖」——但强趋势里过热也能再涨一阵 |
| **波动通道** | 布林带 | 价格相对「正常波动带」是贴上沿还是下沿 |
| **量能** | 成交量均线等 | 放量上涨更像真有人买；缩量拉升更虚 |
| **信号摘要** | 各指标译成中文结论 + 综合「看涨/看跌/中性」 | 机器先投票：多数偏多还是偏空 |
| **形态 / 支撑阻力** | K 线形态、枢轴点等 | 「大概哪里有挡板、哪里有地板」的参考 |

> 💡 **怎么用**：技术面回答的是「走势与买卖力量的痕迹」，**不是公司好不好**。单独看技术面很容易被骗——所以 DeepSeek 要拿它去和资金、基本面对照。

更细的指标清单见 [technical_analysis.md](./technical_analysis.md)。

#### 4.2.2 「基本面与估值评分」是什么？

可以把它想成：**先问公司本身赚不赚钱、负债厉不厉害，再问现在股价贵不贵**。

- **基本面**：看财务报表一类信息——比如赚得多不多、负债沉不沉重、成长是否难看。像体检：肝肾功能好不好。  
- **估值**：用常见「尺子」衡量贵贱，例如 **PE（市盈率）**、**PB（市净率）**——大意是「你为每块利润/净资产付了多少钱」。行业不同，正常区间差很多，所以**不能只看绝对值**。  
- **评分**：Jarvis 会把多维信息压成大约 **0～100** 的分数（盈利、成长、估值、偿债等加权）。分数高 = 按规则看起来更「健康/不那么贵」；分数中等也可能是数据缺失被打成「无信息中评」。

> 💡 **怎么用**：基本面偏「慢变量」——公司质量不会一天变完。但**好公司也可能买贵了**；差公司也可能被题材炒起来。DeepSeek 的工作是说清：底子如何 × 贵不贵 × 和盘面是否打架。

更细的评分维度见 [fundamental_analysis.md](./fundamental_analysis.md)。

#### 4.2.3 「XGBoost：方向、置信度、概率分布、重要特征」是什么？

先记住一句：**这是电脑用历史数据练出来的「涨/平/跌天气预报」**，不是算命、也不是公司调研结论。

| 词 | 白话 |
|---|---|
| **XGBoost** | 一种机器学习模型名字（你不必会调参）。在 Jarvis 里，它根据很多历史特征，预测这只股票**未来若干交易日**更可能落在哪一类 |
| **方向** | 输出三类之一：**涨 / 平 / 跌**（相对某个收益阈值的粗分类，不是精确涨幅） |
| **置信度** | 模型对自己选中那一类有多「自信」（大致等于该类概率）。高也不等于必中 |
| **概率分布** | 三类各自的概率，例如涨 55%、平 30%、跌 15%。要比只看一个「涨」字完整——若涨和平差不多，说明模型其实很犹豫 |
| **重要特征**（若有） | 模型觉得这次判断主要靠哪些输入（如某类动量、波动、均线距离等）。帮你理解「它凭什么这么说」，但仍可能过拟合 |

> 💡 **怎么用**：把它当**参考天气**，写进 DeepSeek 材料是为了让 AI 交叉验证；**不要**因为模型说「涨 70%」就满仓。没跑过/没缓存时，这项会空着——报告照样可以写，只是少了一路证据。

技术细节见 [model_xgboost.md](./model_xgboost.md)。

### 4.3 它输出什么

按系统提示，报告大致应包含：

1. **一句话结论**（方向 + 概率 + 时间框架）  
2. **多维度交叉分析**（技术 × 资金 × 基本面 × 情绪）  
3. **量价关系**（基于原始开高低收量数据）   
4. **关键矛盾点**及解读  
5. **空仓 / 轻仓 / 重仓**三类操作建议  
6. **关键价位与触发条件**  
7. **风险与止损**  
8. **1 周 / 2 周** 乐观·中性·悲观情景及概率  

另外还有 reasoning（思考过程）可供你对照“它是怎么想的”。

### 4.4 有没有二次复核 / 硬门控？

- **本功能本身**：没有“Top5 否决”那种扫描硬门控；它是单股深度报告。
- **它被别处复用**：左侧推荐的 Top5 还会再跑一遍本模块的**轻量深度方向判断**（只输出看多/看空/中性，技术说明见 [llm_reasoning.md](./llm_reasoning.md)），用来否决“短期说买、深度却看空”的矛盾票。那是推荐扫描的纪律，不是你在本页点分析时的流程。

### 4.5 和「AI 股票推荐」的关系（为何曾感觉冲突）

很多人会：推荐里看到「买入」→ 丢进本页 DeepSeek 分析 → 报告又写空仓宜观望 / 等回调，感觉系统在打架。

| | 说明 |
|---|---|
| **以前为何打架** | 推荐 Layer3 用另一套叙事（偏「2 周～3 个月赚 10%+」选股）；本页深度报告用交叉验证 + **1～2 周情景** + **空仓/轻仓/重仓**。尺子不同，语气必然冲。轻量复核只否决「看空」，「中性」仍可留在推荐列表。 |
| **现在如何对齐（2026-08）** | 左右侧 Layer3 与轻量复核，与本页深度分析**共用同一人设骨架**（`deepseek_shared_persona_rules`）。推荐的「买入」被要求等价于：**按深度口径，空仓者现在适合建仓**。 |
| **仍可能看到差异** | ① 推荐是扫描当时的快照，你稍后分析时价量资金可能已变；② 推荐是漏斗里的相对候选，本页是绝对深挖长文，仍会把「买点不好」写清楚。这时应把本页的**空仓建议 / 矛盾点**当作更高优先级的复检。 |

推荐侧说明见 [strategy-unified-left-right-deepseek.md](./strategy-unified-left-right-deepseek.md) §4.5。

## 5. 适合什么行情 / 不适合什么

| 更适合 | 不太适合 |
|---|---|
| 你已经有候选股，想系统化复盘 | 你完全没有标的，只想“今天买啥”（请用推荐扫描） |
| 信号互相打架，需要人把逻辑梳顺 | 指望它给出“明天必涨到 X 元”的精确点位 |
| 持仓中，想按浮盈浮亏调整策略 | 超短线隔夜博弈（请用午盘 T+1） |
| 中短期（约 1～2 周）决策参考 | 纯长线主题投资（请用长期推荐） |

### 常见误用

- **把概率当承诺**：“写了 70% 就满仓” → 错。  
- **忽略矛盾段**：报告专门写了“关键矛盾点”，那往往是最该盯的风险。  
- **材料没齐就当真**：没有资金数据却大谈主力意图 → 可信度下降。  
- **用它代替止损**：报告给了止损感，执行仍靠你。

## 6. 报告怎么读（小白对照表）

| 你看到的内容 | 含义 | 小白怎么用 |
|---|---|---|
| 一句话结论 | 总方向 + 概率 + 时间 | 先读这句，建立预期，再往下验证 |
| 交叉分析 | 各维度是否共振 | 共振多 → 逻辑更顺；矛盾多 → 谨慎或观望 |
| 量价关系 | 放量涨/缩量跌等 | 无量空涨通常更虚 |
| 关键矛盾点 | AI 自己标出的别扭处 | **必读**；别只看看好的半边 |
| 空仓建议 | 能不能建、什么价、分几批 | 还没买的人重点看 |
| 轻仓 / 重仓建议 | 加仓还是减仓 | 已有仓位的人重点看 |
| 关键价位 | 支撑、阻力、触发条件 | 当锚点，不是绝对成交价 |
| 情景分析 | 好/中/坏三种路径 | 先想好“坏情景我怎么办”再行动 |
| Reasoning | 模型思考链 | 用来检查逻辑是否胡扯 |

## 7. 风险与纪律（必读）

1. **LLM 会幻觉**：数字、价位可能写错；重要价位请对照 K 线与自己的交易软件。  
2. **模型不是水晶球**：历史拟合好 ≠ 未来有效。  
3. **成本与耗时**：DeepSeek 长报告吃 tokens；适合重点股票，不适合对全市场逐只狂轰。  
4. **仓位纪律**：单票不梭哈；分批建仓；预设止损。  
5. **T+1**：今天冲动追高，明天才能认错——冲动成本更高。

## 8. 和另外几套的区别

| | 本功能：单股 DeepSeek 分析 | 左侧+右侧推荐 | 长期推荐 | 午盘 T+1 | 优质低估 |
|---|---|---|---|---|---|
| **输入** | 你指定 1 只代码 | 全市场扫描 | 新闻/主题驱动 | 午盘全市场快筛 | 全市场价值漏斗 |
| **周期** | 约 1～2 周研判 | 约 1～2 周（DeepSeek 终审口径） | 约 3 个月～1 年 | **隔夜**（尾盘买→次日早盘卖） | 约 6 个月～2 年 |
| **DeepSeek 角色** | 深度研报作者（尺子源头） | 同一人设的买入终审 +（左侧）深度复核 | 主题提炼与精选 | 游资隔夜裁判 | 独立价值终审 |
| **输出** | 长报告 + 情景 | 左右两栏推荐列表（各 ≤5） | 主题 + ≤5 只 | 极少（0～3）只极速内参 | ≤5 只；可为 0 |
| **适合谁** | 已有标的要深挖 | 想找短中期机会 | 想抓中期主题 | 能盯盘、敢严格执行止损的超短 | 想配置相对同行更便宜的优质股 |
