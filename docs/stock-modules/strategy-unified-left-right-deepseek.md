# AI 股票推荐（左侧+右侧 · 共享数据）（DeepSeek 策略说明 · 小白版）

**对应功能**：网页工具栏「🤖 AI 推荐」→ 统一面板（左侧短期 + 右侧交易）  
**对应实现**：`unified_scanner.py` + `scanner.py` + `right_side_scanner.py`  
**技术细节**：[unified_scanner.md](./unified_scanner.md) · [scanner.md](./scanner.md) · [right_side_scanner.md](./right_side_scanner.md)  
**最后更新**：2026-08-05（DeepSeek 与单股深度分析共享人设；§4.5 冲突说明）

> ⚠️ **合规提示**：本文解释 Jarvis **如何筛选与判断推荐股**，**不构成投资建议**。推荐可能为 0 只；0 只往往是负责任的结果。

---

## 1. 这是干什么的

### 1.1 一句话

**一次扫描、两套哲学**：系统只抓一遍全市场行情，分别用「左侧抄底」和「右侧跟趋势」两套规则筛股，再让 **DeepSeek 做买入终审**，最后左右两栏各出一份报告。

### 1.2 生活比喻：打折衣服

| | 做法 | 股市对应 |
|---|---|---|
| **左侧** | 衣服还在降价，你觉得够便宜就先买 | 下跌/回调里找“可能被错杀”的票 |
| **右侧** | 衣服止跌并开始回涨，你确认趋势再跟 | 资金回流 + 价格转强后再进场 |

没有绝对谁更好：左侧更便宜但可能继续跌；右侧更踏实但少吃一段利润。

### 1.3 交易节奏 / 持有周期

- **DeepSeek 终审口径（2026-08 起）**：与「A股分析 & AI预测」对齐——主情景约 **1～2 周**，交叉验证 + 空仓是否适合建仓。  
- **左侧 / 右侧规则漏斗**仍可筛出适合稍长持有的结构，但 **AI 买入裁决不再以「2～3 个月赚 10%+」为主叙事**。  
- **共享数据**：行情抓 1 次；个股资金流 / K 线在左右侧之间可复用（内部叫共享缓存 `scan_cache`：同一只股票一侧算过，另一侧可直接复用），省时省钱。

### 1.4 在界面上怎么用

1. 点 **「🤖 AI 推荐」**
2. **勾选 DeepSeek**（强烈建议：判断质量明显高于纯本地小模型）
3. 点开始扫描，看进度：`共享行情` → `左侧…` → `右侧…`
4. 左栏看左侧推荐，右栏看右侧推荐

耗时粗估：左侧常需十几到几十分钟；右侧通常更快。卡住时先看进度条文案。

## 2. 金融逻辑：为什么要这样交易

### 2.1 核心信念

**没有任何一种入场时机在所有行情下都最优**，所以 Jarvis 同时提供两套：

- **左侧信念**：安全边际来自“足够便宜 + 有人悄悄吸筹”。  
- **右侧信念**：趋势是朋友——等**资金态度反转**且**价格确认**，再跟。

### 2.2 先搞懂“主力资金 / 聪明钱”

大资金买卖会在“主力净流入/流出”里留下痕迹。Jarvis 常把阶段粗分为：

| 阶段 | 大白话 | 左侧更关心 | 右侧更关心 |
|---|---|---|---|
| **布局期** | 钱在进、价还没大涨 | ✅ 典型买点区 | 通常还不到“确认” |
| **拉升期** | 钱在进、价已大涨 | 易追高，要警惕 | 可能已偏晚 |
| **出货期** | 价还在涨/晃，钱在出 | ❌ 硬否决 | ❌ 不该追 |
| **观察期** | 信号不清 | 等待 | 等待 |

**左侧**：喜欢“资金悄悄进、价格还没飞”。  
**右侧**：要“前阵子钱在出 → 最近几天钱持续回来”，且价格站上短期均线。

### 2.3 A 股现实

- **T+1**：追涨停很容易被动隔夜；两侧规则都抑制极端追高。  
- **涨跌停**：流动性瞬间消失；筛选会避开过于疯狂的涨幅区。  
- **ST / 垃圾流动性**：直接排除。  
- **宁缺毋滥**：条件不满足就 **0 推荐**——这是功能，不是故障。

### 2.4 左侧在赌什么 / 右侧在赌什么

| | 左侧 | 右侧 |
|---|---|---|
| 赌的优势 | 均值回归 + 吸筹尚未反映到价格 | 趋势延续 + 资金回流真实性 |
| 主要风险 | 抄在半山腰，阴跌不止 | 假突破、冲高回落、死扛不止损 |
| 更适配 | 震荡、回调、熊末有结构性机会 | 趋势启动、主升或明确反转段 |

## 3. 筛选漏斗（规则层先干活）

### 3.1 总览：一次行情，两条漏斗

```
        [一次共享全 A 行情快照]
                 │
     ┌───────────┴───────────┐
     ▼                       ▼
 左侧 scanner              右侧 right_side
 Layer1 快筛               Layer1 活跃度快筛
 Layer2 排序/打分          Layer2 资金反转硬过滤
 Layer3 DeepSeek 可买性    Layer3 DeepSeek 右侧判断
 (+ Top5 深度复核)         
     │                       │
     └───────────┬───────────┘
                 ▼
        左栏报告 + 右栏报告
```

---

### 3.2 左侧漏斗（抄底 / 可买性）

```
全市场 ~5000
  → Layer1：流动性 + 估值区间 + 不追涨停偏好 → ~100
  → Layer2：截面 XGBoost 排序（失败则规则多因子）→ 缩小
  → 资金面硬门控：缺数据 / 出货 / 大额流出 → 剔除
  → Layer3：DeepSeek（Top 一批）做「买入 vs 不买入」
  → 分数≥门槛 取最多 5 只
  → Top5 再做 DeepSeek 轻量深度复核（看空则否决）
```

**Layer1 直觉（不必背数字）**  
- 不要 ST；不要流动性极差。  
- PE 落在“还算合理”的区间（过低也可能是价值陷阱，不是越低越好）。  
- **涨太多的降分**——左侧讨厌追高。  
- 温和换手优于疯狂换手。

**Layer2 直觉**  
- 主路径：在候选里做**横截面排序**（谁相对同行更可能有超额），并尽量行业分散。  
- 回退路径：技术 + 基本面 + 情绪 + 资金等加权。  
- 资金数据会尽量抓；抓不到会打标，后面禁止“瞎买”。

**硬规矩（比 AI 更优先）**

- 资金流向缺失 → 不能最终「买入」  
- 主力出货期 → 否决  
- 近 3 日主力大幅净流出 → 否决  
- Top5 深度复核若 **看空** → 从推荐里拿掉  

> 设计哲学：**宁可 0 只，也不推“看起来很强但不该买”的票。**

---

### 3.3 右侧漏斗（确认后跟进）

```
全市场 ~5000
  → Layer1：活跃、可交易、涨幅别极端 → ~60
  → Layer2：必须同时近似满足
        · 近 10 日主力偏流出
        · 近 3 日主力转持续流入且力度够（净占比门槛）
        · 价格站上 MA5（短期转强）
        · （加分）逼近/突破 MA20、放量、RSI 未疯狂超买
  → 未达资金反转硬条件 → 直接淘汰（不进 DeepSeek）
  → Layer3：DeepSeek 右侧入场判断 + 止损/目标价
```

**大白话翻译右侧信号**  
> “这票前一阵被大资金扔过，最近几天大资金又持续买回来了，而且价格已经止跌转强——这时再考虑跟。”

无信号 → **暂无右侧推荐** 非常常见，请耐心。

## 4. DeepSeek 在这里扮演什么角色

### 4.1 规则层 vs DeepSeek

| 阶段 | 谁做主 |
|---|---|
| Layer1 / Layer2 | **规则与模型打分**——把五千只收到可人工看的数量 |
| Layer3 | **DeepSeek（勾选时）**——对候选做「买 / 不买」终审并写理由、风险、策略 |
| 左侧额外 | Top5 **深度复核**（轻量单股方向）——防止和深度分析打架 |

未勾 DeepSeek 时会走本地 LLM，质量通常明显弱一档。

### 4.2 左侧：DeepSeek 看什么、输出什么

**常看到的信息（丰富 prompt）**  
Layer2 分数与分项、估值与价量、资金阶段、情绪、（若有）截面排名 / 行业中性 alpha、超买标记等。资金缺失时会有**强警告**：禁止只凭技术面给买入。

**输出结构（概念上）**  
- **裁决（verdict）**：买入 / 不买入（展示上未过关常呈观望）  
- 分数、核心理由、主要风险  
- 建议买入价区间、仓位与持有路径/止损感  
- **人设与深度分析同一套尺子**：交叉验证、约 1～2 周情景；**仅当空仓者现在适合建仓**才可判买入（否则不买入）

判后若仍触发资金硬门控，系统会把「买入」**降级**为观望。

### 4.3 右侧：DeepSeek 看什么、输出什么

**角色定位**：与深度分析**同一人设**，再叠加「确认后跟进」；必须是**带止损的趋势交易员**，不是死多头。资金反转硬过滤仍在规则层。

**输出重点**  
- 是否右侧入场（买入 / 不买入）——映射仍是「空仓现在能不能在确认位建仓」  
- 理由（资金反转是否真、趋势是否假突破、交叉验证）  
- **严格止损价**、约 1～2 周情景下的短周期目标价、操作策略  

### 4.4 二次复核（仅左侧 Top5）

对最终候选人再用与深度分析**同一共享人设**的轻量方向判断（看多 / 看空 / 中性）：

- **看空** → 否决，避免“推荐买 + 深度空”的硬矛盾  
- **看多 / 中性** → 可保留；前端可显示复核标签  

右侧主要靠 Layer2 硬过滤 + Layer3（已统一人设），不走同一套 Top5 复核链路。

### 4.5 和「A股分析 & AI预测」的关系（为何曾感觉冲突）

| | 以前容易打架的原因 | 现在怎么对齐 |
|---|---|---|
| 人设 / 周期 | 推荐 Layer3 主推「2 周～3 个月赚 10%+」；深度报告主推交叉验证 + 1～2 周情景 | **共用** `deepseek_shared_persona_rules`（交叉验证、1～2 周、空仓/轻仓/重仓） |
| 输出形式 | 推荐只要买入/不买入；深度写空仓「等回调」像「不易买」 | 推荐买入 **显式映射**「空仓者现在适合建仓」；不适合则不买入 |
| 仍可能不同的 | 扫描时点 vs 你稍后分析时点；相对筛选 vs 绝对深挖长文 | **正常**：深挖仍是复检；若推荐已买入、深挖仍劝等买点，优先信深挖的空仓建议 |

详细单股侧说明见 [strategy-ashare-analysis-deepseek.md](./strategy-ashare-analysis-deepseek.md) §4.5。

## 5. 适合什么行情 / 不适合什么

| 场景 | 更该看哪一栏 |
|---|---|
| 大盘震荡、个股回调、情绪冰点后的结构性机会 | **左侧** |
| 指数或板块启动、趋势明确、资金回流迹象多 | **右侧** |
| 两边都有 | 机会偏多，可分散，但仍要各自纪律 |
| 两边都空 | **今天没好机会**——观望是正确答案 |
| 你完全不能接受浮亏 | 少碰左侧；右侧也必须设止损 |
| 你想隔夜超短 | 不要用本功能，去看午盘 T+1 |

### 常见误用

- 把左右侧当成“对同一只股票的同一判决”——它们是**不同时机哲学**。  
- 左侧 0 推荐就强行在 Layer1 落选股里自己找——等于绕过风控。  
- 右侧有票却不设止损——右侧最怕死扛。  
- 不勾 DeepSeek 却抱怨“推荐很玄”。

## 6. 报告怎么读（小白对照表）

### 6.1 左侧卡片

| 字段 | 含义 | 怎么用 |
|---|---|---|
| 综合得分 | 可买性综合分 | 一般要过门槛才出现 |
| PE / 分项分 | 估值与多维质量 | 多维都高更舒服 |
| DeepSeek / 本地标签 | 谁判的 | 优先信 DeepSeek |
| 深度复核 | 二次方向 | 看空不会出现在最终列表 |
| 推荐理由 / 风险 | 逻辑与雷 | **两段都要读** |
| 买入区间 / 策略 | 价与仓位参考 | 锚点，不是必成交价 |

### 6.2 右侧卡片

| 字段 | 含义 | 怎么用 |
|---|---|---|
| 资金反转摘要 | 核心信号 | 看 3 日流入与力度 |
| 站上 MA5 / MA20 | 趋势确认 | 没确认就别自行脑补 |
| 严格止损 | 铁律价 | 跌破就走 |
| 目标价 | 预期兑现区 | 到了考虑止盈 |
| DeepSeek 右侧判断 | 终审 | 读理由是否承认假突破风险 |

## 7. 风险与纪律（必读）

**通用**  
- 推荐 ≠ 必涨；控制单票仓位；分批。  
- 0 推荐时不要“为了交易而交易”。  

**左侧特有**  
- 可能阴跌；要有时间与心态扛波动，或干脆小仓。  
- 相信硬门控：没有资金数据就不要自己脑补主力。  

**右侧特有**  
- **止损必须执行**；把超短思维拖成中线套牢，是右侧最常见失败。  
- 假突破会快速打止损——这是成本，不是羞辱。

## 8. 和另外几套的区别

| | 本功能（左右统一） | 单股 DeepSeek 分析 | 长期推荐 | 午盘 T+1 | 优质低估 |
|---|---|---|---|---|---|
| 目的 | 全市场找短中期候选 | 深挖你指定的 1 只 | 主题/宏观约 3 个月～1 年 | 隔夜套利 | 同业低估+质量，约 6 个月～2 年 |
| DeepSeek | 与深度分析**同一人设**的终审（+左复核） | 写长研报（尺子源头） | 主题与精选 | 游资隔夜裁判 | **独立价值人设**（周期/陷阱/商誉） |
| 输出数量 | 左 ≤5；右 ≤5（常为 0） | 1 份报告 | 主题 + ≤5 只 | 通常 0～3 | ≤5（常为 0） |
| AI 主周期 | 约 1～2 周情景 | 约 1～2 周情景 | 约 3 个月～1 年 | 隔夜 | 约 6 个月～2 年 |
| 共享行情 | ✅ 左右共享 | 不适用 | 另套信号 | 独立午盘快照 | 独立全市场快照 |

### 怎么配合用（极简）

```
先跑 AI 推荐 → 看哪边有票
  → 看上某只 → 再开「A股分析 & AI预测」做 DeepSeek 深挖
  → 仍想隔夜搏一把 → 另用午盘（别和左右策略混仓位）
  → 想布局约 3 个月～1 年主题 → 看长期推荐
  → 想中长期配置相对同行更便宜的优质股 → 看优质低估（已排除创业板）
```
