# 近5年高二次突破（DeepSeek 策略说明 · 小白版）

**对应功能**：网页「🤖 AI 推荐」第三栏；以及「A股分析 & AI预测」报告中的近5年高段落。  
**对应实现**：`ath_rebreak.py` + `ath_rebreak_scanner.py`  
**最后更新**：2026-08-30

> ⚠️ 本文解释 Jarvis **如何标记一种价格结构**，**不构成投资建议**。

## 一句话

价格先收盘站上 **近 5 年高（前复权）** → 这只是标杆 → 回落整理 → **再收盘突破** 才是买点候选。

## 和左右推荐的关系

- **左侧**是抄底/估值，和本策略相反，漏斗 **不改**。
- **右侧**是资金反转 + 均线确认；本策略是独立第三栏，专门管「前高回踩再突破」。
- 这不是圣杯：A 股假突破、打板出货很常见。涨停那天往往 **买不到**（T+1）。

## 你在报告里会看到

- 标杆价格与第一次突破日期
- 回踩标签（跌回标杆下方 / 3%–8% 旗形 / 浅回踩）
- 是否为近 3 日活信号、是否涨停不可买
- DeepSeek 仍要交叉验证资金与估值；检测结果以代码为准，不要让模型用近 20 日表自己发明前高

v1 **不是**上市首日至今的最高价；老股的泡沫高点可能根本不在这 5 年窗口里。
