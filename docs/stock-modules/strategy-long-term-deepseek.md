## 1. 这是干什么的

### 1.1 一句话

不盯着“今天谁涨停”，而是读最近约 **14 天**的国际/科技新闻、风险预警、热门板块与市场情绪，并强制看一眼 **黄金/白银**，让 DeepSeek 归纳 **约 3 个月～1 年的投资主题**，再映射到 A 股里最多约 **5 只**更值得中长期跟踪的标的。

### 1.2 生活比喻

像规划「下一季穿什么」而不是「明天中午吃什么」：

- 你先看天气趋势、流行色、面料新闻（= 宏观与产业新闻）  
- 再看贵金属像“避险温度计”（金/银）  
- 最后才决定买哪几件单品（= 个股），而且件数严格控制  

### 1.3 交易节奏 / 持有周期

- **时间框架**：模型要求按 **约 3 个月～1 年** 思考；`time_horizon` 常见取值为 **`3个月` / `6个月` / `1年`**（报告里也常强调半年到一年的远景）。  
- **不是 T+1 隔夜**，也不是左侧那种“回调两周博反弹”的短线可买性扫描。  
- **宁缺毋滥**：主题不成立或个股空间评估太差 → 可以很少推荐甚至没有。

### 1.4 在界面上怎么用

1. 打开 **长期推荐** 面板  
2. **勾选 DeepSeek**（主题提炼与最终精选质量更稳）  
3. 开始分析，等待主题列表 + 精选个股报告  
4. 阅读时先看「主题逻辑 / 催化剂 / 风险」，再看个股  

前提：新闻与简报数据路径可用（系统会读近两周的世界新闻、AI 简报等）；贵金属来自上海金交所相关基准价数据。

## 2. 金融逻辑：为什么要这样交易

### 2.1 核心信念：主题投资（Thematic Investing）

短期股价噪声极大；中期更大的驱动往往是：

- 政策方向（国内产业政策、海外监管）  
- 技术与产业趋势（AI、能源、制造升级等）  
- 地缘与风险偏好（避险 ↔ 风险资产切换）  
- 大宗商品与通胀预期（金、银是常用观察窗）  

**长期推荐**赌的是：用 LLM 把嘈杂新闻压成少数清晰主题，再在主题里挑「逻辑顺 + 位置还没过热」的标的。

### 2.2 为什么强制看黄金 / 白银？

| 品种 | 常被当成什么 | 对 A 股的启发（简化） |
|---|---|---|
| **黄金** | 货币信用、实际利率、避险 | 避险升温时，相关情绪与资源股可能被带动 |
| **白银** | 工业属性更重 + 一定货币属性 | 工业复苏预期与金银比相对价值 |
| **金银比** | 金贵还是银贵的相对尺子 | 比例过高/过低会提示“银相对便宜/偏贵”一类叙事 |

这不是让你“只炒黄金股”，而是给主题分析一个**宏观温度计**，避免纯看科技新闻而忽略风险偏好切换。

### 2.3 A 股特殊点

- 海外新闻 → A 股常常是**映射交易**（同样叙事，标的换成国内链上公司）。  
- 政策与主题轮动快，但**个股可能已经涨很多**——所以后面有“上涨空间评估”，过热的会降权。  
- 过滤 ST、过宽但仍会踢掉极端/缺失 PE、过小市值，降低主题炒作里的地雷密度（**真正质量关在后面的空间评估 + DeepSeek 终选**）。

### 2.4 这套策略在赌什么优势

1. **信息带宽**：你一个人难读完两周全球新闻；系统先摘要。  
2. **结构化主题**：强迫写出逻辑、行业、催化剂、风险、信心，而不是“感觉要涨”。  
3. **空间约束**：用历史分位、52 周位置、技术与资金等，避免“主题对但票已在山顶”。

## 3. 筛选漏斗（规则层先干活）

```
① 收集近 14 日信号
   世界新闻 + AI/科技简报 + 黑天鹅预警 + 热门板块 + 全球/市场情绪
② 贵金属分析（金/银趋势、金银比、LLM 展望）
③ DeepSeek：提炼投资主题（约 3～5 个候选主题结构）
④ 主题 → 映射热门板块/行业成分与龙头 → 候选池
⑤ 规则过滤：非 ST、排除极端/缺失估值等硬条件（**PE 带宽较宽，约 0～200**，不是“合理估值精选”）、市值门槛等
⑥ 逐只「上涨空间评估」打分，动态保留更有空间的一半量级
⑦ DeepSeek：最终精选 ≤ 5 只（可更少）——**真正的质量关多在这里 + 上一步空间评估**
⑧ 落盘 Markdown / JSON，并可写入检索库（RAG，方便以后聊天时被搜到）
```

### 每层在干什么（大白话）

| 步骤 | 作用 |
|---|---|
| 信号收集 | 回答“世界上最近在吵什么、怕什么” |
| 贵金属 | 回答“避险与商品温度如何” |
| 主题 LLM | 把噪声变成可投资的故事线 |
| 映射个股 | 故事落到 A 股可交易标的 |
| 硬过滤 | 去掉 ST、过小市值、极端/缺失 PE 等壳；**不代表估值已经“合理”** |
| 空间评估 | 同样主题下，谁还没涨到“过分” |
| 最终精选 | DeepSeek 做“宁缺毋滥”的裁员 |

### “暂无推荐”正常吗？

**正常。** 例如：新闻窗很空、主题风险过大、候选全被空间评估打死、或最终模型认为不宜出手。长期策略最怕的是“为了凑满 5 只而硬推”。

## 4. DeepSeek 在这里扮演什么角色

### 4.1 规则层 vs DeepSeek

| | 规则 / 数据层 | DeepSeek（勾选时优先） |
|---|---|---|
| 收集新闻、板块、金银指标 | ✅ | 解读与展望 |
| 主题命名与逻辑 | 结构约束 | **主笔**写出主题 JSON |
| 个股映射与过滤 | ✅ 字符串匹配板块 + 门槛 | 不替代硬过滤 |
| 空间打分 | ✅ 五维规则分 | 参考这些分做最终裁选 |
| 最终 ≤5 只 | 候选截断 | **终审精选** |

未开 DeepSeek 时会落到本地 Ollama；主题质量通常更不稳定。

### 4.2 DeepSeek 会看到哪些信息

- 近 14 日新闻与简报摘要（多源拼接）  
- 黑天鹅 / 风险扫描要点  
- 热门板块列表  
- 市场情绪指标摘要  
- 金/银量化特征 +（另一步）贵金属 LLM 展望  
- 进入终选时：候选股列表及空间评估结论等文本化材料  

### 4.3 它输出什么

**主题阶段（概念字段）**  
- 主题名称、逻辑、相关行业  
- 催化剂、时间框架、风险、信心 等  

**终选阶段**  
- 最多 5 只：为什么入选、与主题如何挂钩、风险、持有思路（以实际报告为准）  
- 允许输出更少；质量优先于数量  

### 4.4 有没有二次复核硬门控？

- **有规则硬过滤**（ST、PE、市值、空间评估截断）。  
- **没有**左侧那种“Top5 深度看空否决”的同一套机制；终选本身就是 DeepSeek 裁员。  
- 黑天鹅模块提供的是**风险输入**，不是自动清仓按钮——仍要你在主题风险段自己判断。

## 5. 适合什么行情 / 不适合什么

| 更适合 | 不太适合 |
|---|---|
| 你想建立「未来一两个月看什么主线」 | 你想今天下午买、明天早上卖 |
| 新闻驱动的产业/政策窗口 | 纯短线情绪投机、打板 |
| 组合里需要主题分散 | 已经满仓短线票还想再加杠杆叙事 |
| 愿意跟踪催化剂是否兑现 | 拒绝读逻辑、只看推荐列表代码 |

### 常见误用

- 把长期推荐当日内买卖点。  
- 主题对就全仓单一龙头——主题内也要个股风险与估值。  
- 忽略报告里的 **risk / 催化剂是否落空**。  
- 金银只是温度计，不等于“必须买黄金股”。

## 6. 报告怎么读（小白对照表）

| 内容 | 含义 | 怎么用 |
|---|---|---|
| 贵金属段 | 金/银趋势与相对价值 | 先判断大环境偏避险还是偏风险 |
| 主题列表 | 中期故事线 | 先选你信的故事，再看股 |
| 催化剂 | 可能触发行情的事件 | 列出观察清单；落空要减预期 |
| 时间框架 | 主题预计发酵窗口 | 用来设“多久没兑现就复盘” |
| 主题风险 | 故事怎么死 | **必读**；比涨跌幅重要 |
| 入选个股 | 故事落点 | 对照空间评估：是否已炒作过度 |
| 信心/评分 | 模型自信程度 | 低信心 → 更小仓或只观察 |

---

## 7. 风险与纪律（必读）

1. **叙事风险**：AI 会把新闻讲成很顺的故事；故事可以错。  
2. **映射风险**：海外主题 ≠ 国内映射股一定受益（竞争格局、估值、政策可能不同）。  
3. **拥挤交易**：热门主题常已部分定价；空间评估就是为了泼冷水。  
4. **仓位**：主题投资仍要分散；单主题单票不赌命。  
5. **复盘纪律**：催化剂到期未兑现 → 减仓或退出，不要“改口变长线”。

## 8. 和另外几套的区别

| | 长期推荐 | 左右统一推荐 | 单股分析 | 午盘 T+1 | 优质低估 |
|---|---|---|---|---|---|
| 驱动 | 新闻/政策/贵金属主题 | 价量+资金+截面/反转 | 你指定个股深挖 | 上午盘量价资金 | 同业低估+财务排雷 |
| 周期 | 约 3 个月～1 年 | 约 1～2 周（DeepSeek 终审） | 约 1～2 周情景 | 隔夜 | 约 6 个月～2 年 |
| DeepSeek | 主题 + 终选 | 与深度分析**同一人设**的买入终审（+左复核） | 长研报 | 游资隔夜裁判 | 独立价值人设 |
| 典型输出 | 主题卡 + ≤5 股 | 左右列表 | 1 份深度报告 | 0～3 只极速内参 | ≤5 只；可为 0 |
