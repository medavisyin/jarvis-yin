# AI 午盘极速隔夜套利 (T+1)（DeepSeek 策略说明 · 小白版）

**对应功能**：网页「⚡ 午盘推荐」/ AI 午盘极速隔夜套利 (T+1)  
**对应实现**：`scripts/stock/midday_scanner.py`  
**技术细节**：[midday_scanner.md](./midday_scanner.md)  
**最后更新**：2026-08-05（§8 对照表与共享 DeepSeek 尺子对齐）

> ⚠️ **合规提示**：这是**超短线、高难度、强纪律**策略说明，**不构成投资建议**。做不了严格执行止损，请直接跳过本功能。  
> 本功能 DeepSeek 人设仍是「游资隔夜裁判」，**不与**单股深度分析 / 左右推荐的约 1～2 周共享尺子混用。

---

## 1. 这是干什么的

### 1.1 一句话

在交易日 **中午休市后（建议 12:30～12:45）**，根据**上午盘**已经走出来的量价与资金线索，极速筛出极少数标的，意图是：

> **今天下午尾盘附近买入 → 明天早盘（约 9:30～10:00）冲高了结**  
> 这就是 A 股 **T+1 隔夜套利** 的一种玩法。

DeepSeek 在这里扮演的是 **「游资隔夜裁判」**：只回答「隔夜搏不搏」，并要求止损里写清早盘不利怎么跑；报告还会**固定附带**冲高失败纪律文案。

### 1.2 生活比喻

像买演唱会黄牛票的「隔夜倒手」：

- 中午你确认：这票上午真有人抢（量价、资金）。  
- 下午入场拿到票。  
- 第二天开场有热情就立刻转手；开场冷清就**马上离场**，绝不改口说“我本来就想收藏”。  

超短线最怕的就是：**计划是隔夜，执行变成套牢长持**。

### 1.3 交易节奏（必须背下来）

| 时间 | 你在干什么 |
|---|---|
| **12:30～12:45** | 跑本扫描，读内参 |
| **13:00～15:00** | 若仍符合计划，考虑尾盘区域执行买入（实盘仍看当时盘口） |
| **次日 9:30～10:00** | 冲高卖出锁定隔夜溢价；走不动则按失败预案离场 |
| **10:00 后还拿着“幻想反弹”** | ❌ 策略已经变味，风险急剧上升 |

每日通常 **0～3 只**；刷满约 3 只「买入」可早停。没有合格票 → **空仓是胜利**。

### 1.4 在界面上怎么用

1. 打开 **午盘** 面板  
2. **勾选 DeepSeek**（推荐；角色是「游资隔夜裁判」）  
3. 仅在午休窗口启动；不要开盘疯狂刷新当玩具  
4. 读「理由 / 风险 / 止损 / 止盈」以及报告里的**冲高失败纪律**后再决定是否动手

## 2. 金融逻辑：为什么要这样交易

### 2.1 核心信念

A 股 **T+1**：今天买的股票，最早明天才能卖。  
因此出现一种专门吃「隔夜价差 / 情绪溢价」的玩法：

- 上午多空博弈告一段落，主力若真想做次日高开或惯性冲高，常在午后继续表达。  
- 你在信息相对完整的午盘决策，缩短“上午瞎追涨停、尾盘被闷杀”的暴露时间。  
- 目标不是挖到伟大公司，而是概率上捕捉**次日早盘流动性脉冲**。

### 2.2 为什么强调均线、量比、主力？

| 要素 | 大白话 |
|---|---|
| 站上短期均线、多头排列 | 只做顺势，不做逆势抄跌 |
| RSI 强但未疯狂超买 | 要有动能，但不要已经“抽干” |
| 量比放大、换手与成交额够 | 真有人参与，不是冷门自嗨 |
| 市值落在弹性区 | 太小易崩、太大弹性差；策略锁定甜点区间 |
| 主力近几日仍偏吸筹/流入 | 避免纯散户情绪末端 |

### 2.3 A 股特殊风险（本策略放大版）

- **隔夜政策 / 外盘**：美股暴跌、突发新闻，次日低开直接打穿计划。  
- **下午变盘**：12:30 看起来很美，14:30 可能主力反手。  
- **涨停博弈**：涨幅已过高的票，次日空间可能被透支——规则层会砍掉过高涨幅。  
- **流动性瞬间消失**：跌停或极度弱市时，止损价只是愿望。  

### 2.4 这套策略在赌什么优势

1. **时间切片优势**：用上午完整信息做决策，而不是开盘 5 分钟情绪。  
2. **严格漏斗**：多数票根本进不了 DeepSeek，降低“随便找个热门隔夜”的冲动。  
3. **失败预案写进报告**：模型须给出带早盘离场纪律的止损价；报告生成时还会**固定附上**「约 10:00 前清仓」类纪律句——两者一起约束执行。  

它**不赌**“我看盘神准”，它赌“规则 + 短线裁判 + 你的执行”。

## 3. 筛选漏斗（规则层先干活）

```
全 A 实时快照（AkShare → 东财直连 → 新浪分页 高可用）
        ↓
Layer1 午盘量价快筛
  温和偏强上涨、放量、流动性与市值区间
  排除 ST、过高涨幅；主板/创业板为主（**排除科创板 688、北交所**等）
  → 最多约几十只（量级受规则约束）
        ↓
Layer2 多因子并发打分（规则，不用 XGBoost）
  均线位置、RSI 区间、主力资金阶段等加权
  → 先取综合分 Top 约 10
        ↓
Layer3 DeepSeek「游资隔夜裁判」（可 3 路并发，推理偏快）
  为赶午休决策窗，**通常只对 Top10 里前约 6 只**做裁决
  裁决（买入 / 观望）；早停：凑满约 3 只买入即可收工
        ↓
极速内参 Markdown + JSON（可推送；内含固定冲高失败纪律句）
```

### Layer1 直觉（不必背参数，要懂目的）

- **不要太弱**：上午还在跌/完全没动的，不做隔夜英雄。  
- **不要太强**：涨幅已经接近危险区的，次日容易“高开低走”。  
- **要有量**：量比、换手、成交额证明有真实博弈。  
- **市值甜点**：追求短线弹性，避开极端小盘雷与超大盘钝感。  
- **板块范围**：主做沪深主板与创业板；科创板 / 北交所不在本策略 Layer1 目标池。  

### Layer2 直觉

- 价格相对 **MA5 / MA20** 的位置：偏多头。  
- **RSI** 落在“强但未过热”的带状区。  
- **资金**：近 3/5 日主力与吸筹类信号权重大——隔夜更怕主力其实在出货。  

### “暂无推荐”正常吗？

**非常正常，而且应该高兴。**  
超短线是少数服从多数的游戏：大多数交易日根本不该隔夜。

## 4. DeepSeek 在这里扮演什么角色

### 4.1 规则层 vs DeepSeek

| | 规则层 | DeepSeek |
|---|---|---|
| 初筛与打分 | ✅ 极速、可并发 | 不做全市场遍历 |
| 是否隔夜买入 | 只给候选 | **终审裁决（买入 / 观望）** |
| 买卖框架 | 参数门槛 | 给出限价感、止盈、止损、信心 |
| 失败怎么办 | 报告**固定模板**强调 10:00 前纪律 | 止损字段须体现「开盘半小时内不利则果断离场」 |

本地 LLM 可作为兜底，但短线裁决质量通常不如 DeepSeek。

### 4.2 DeepSeek 的角色设定（你要懂它在扮演谁）

系统提示把它定位为：

> 擅长 **「今日尾盘买、明日早盘冲高卖」** 的 A 股超短线 / 游资策略师。

因此它优化的目标函数接近：

- 隔夜胜率与盈亏比（概念上）  
- 次日早盘可执行性  
- **绝不**把隔夜单合理化成中线投资  

### 4.3 它会看到哪些信息（概念清单）

- 上午涨跌幅、价格、换手、量比、成交额、市值、行业等快照字段  
- Layer2 综合分与关键技术/资金摘要  
- 供短线决策的约束：T+1、避免已高位透支等（体现在提示与规则双重约束）  

### 4.4 它输出什么

典型字段（名称以实际报告为准）：

| 字段 | 含义 |
|---|---|
| 裁决（买入 / 观望） | 终审结论 |
| 综合分 / 信心 | 强度感 |
| 推荐理由 | 为何值得隔夜 |
| 主要风险 | 明日可能怎么死 |
| 建议买入参考价 | 尾盘执行锚点 |
| 止盈目标 | 次日冲高区域 |
| 止损目标 | 失败时离场锚点；提示词要求写清早盘不利如何一刀切 |
| **冲高失败操作建议**（报告栏） | 多为报告**固定附带**的「约 10:00 前清仓」纪律句，不是模型单独吐出的自由字段 |

### 4.5 有没有二次复核？

- 有 **早停**（买满约 3 只不再穷举）。  
- **没有**左侧那种“深度看空否决长逻辑”的复核——因为本策略时间尺度完全不同。  
- 真正的“复核”是你在 **14:30 后**看盘口有没有走坏（资金翻脸、破位）；系统文档也提示下午变盘风险。

## 5. 适合什么行情 / 不适合什么

| 更适合 | 强烈不适合 |
|---|---|
| 你能接受高频止损、小亏当成本 | 不能盯盘、不能次日早盘操作 |
| 市场有短线赚钱效应、交投活跃 | 单边暴跌、流动性枯竭、政策真空雷区 |
| 仓位只拿“小赌怡情”的超短预算 | 用生活费/杠杆资金玩隔夜 |
| 严格执行 10:00 纪律 | “再等等下午或许翻红”型性格 |

### 常见误用

- 把午盘推荐拿去当波段底仓。  
- 上午 10 点就跑扫描（数据语义不对）。  
- 涨停板情绪最高点还要隔夜。  
- 次日弱开却死扛等“回本”。  
- 一天交易多只隔夜，把风险叠加成组合爆炸。

## 6. 报告怎么读（小白对照表）

| 内容 | 含义 | 怎么用 |
|---|---|---|
| 买入 / 观望 | 终审 | 观望=今天不做；别自己加戏 |
| 核心理由 | 上午资金与形态逻辑 | 你看不懂就放弃该票 |
| 主要风险 | 隔夜杀手 | 先写进交易计划 |
| 参考买价 | 尾盘锚点 | 远离锚点太多要重新评估 |
| 止盈 | 次日目标带 | 到了减/清，勿贪 |
| 止损 | 失败价 | 触发就走 |
| 冲高失败纪律 | 策略灵魂（读报告固定句 + 止损价） | **读完才能下单** |
| DeepSeek「游资隔夜裁判」标签 | 谁判的 | 未开 DeepSeek 更需降置信 |

## 7. 风险与纪律（必读）

1. **单笔亏损限额**：超短必须先定最大亏损，再谈盈利。  
2. **时间止损**：次日 10:00 仍弱，按计划离场，不要改期。  
3. **下午二次确认**：推荐产出后若大盘跳水或个股放量砸盘，允许空仓不做。  
4. **仓位隔离**：午盘仓与左右侧波段仓、长期主题仓分开，免得策略互相污染。  
5. **心理**：连续止损后应暂停，而不是加倍。

## 8. 和另外三套的区别

| | 午盘 T+1 | 左右统一推荐 | 长期推荐 | 单股 DeepSeek 分析 |
|---|---|---|---|---|
| 周期 | **隔夜** | 约 1～2 周（DeepSeek 终审） | 约 3 个月～1 年 | 约 1～2 周情景 |
| 运行时刻 | 建议 12:30 后 | 任意交易时段（耗时长） | 任意（偏研究） | 任意 |
| DeepSeek 人设 | 游资隔夜裁判 | 与单股深度分析**同一尺子**（左/右终审） | 主题研究员 | 综合分析师（尺子源头） |
| 数量 | 0～3 | 左 ≤5 + 右 ≤5（常为 0） | ≤5 | 1 只深挖 |
| 失败关键 | 次日早盘时间止损 | 波段止损/门控 | 催化剂落空 | 情景与仓位管理 |
