# MiMo API Implementation Plan

> **For the implementing agent:** Follow this plan task-by-task. Complete each step, verify it works, then move to the next.

**Goal:** Add a Xiaomi MiMo API key and make MiMo selectable everywhere GLM is selectable, using `mimo-v2.6-flash` for text and `mimo-v2.5-tts` for audio when that engine is chosen.

**Architecture:** New `scripts/rag/mimo_chat.py` mirrors the GLM adapter with the OpenAI SDK and pay-as-you-go base URL. `glm_chat.py` only widens two allow-lists so `mimo` survives settings and the stock cloud-provider context. Daily audio and intensive-reading speak switch engines; article audio and the standalone output scripts stay on Edge-TTS. Android stores a key and probes one chat completion.

**Tech Stack:** Python (Flask, OpenAI SDK), React settings page, Kotlin unit tests.

```python
"""Xiaomi MiMo chat and TTS adapter. GLM stays in glm_chat.py."""
from __future__ import annotations

MODEL = "mimo-v2.6-flash"
TTS_MODEL = "mimo-v2.5-tts"
BASE_URL = "https://api.xiaomimimo.com/v1"
_MISSING_KEY = "No MiMo API key configured"

SPEAK_SAMPLE = "(磁性)夜已经深了，城市还在呼吸。我是今晚陪你的人，欢迎收听《午夜电台》。"
SING_SAMPLE = "(唱歌)原谅我这一生不羁放纵爱自由，也会怕有一天会跌倒，Oh no。背弃了理想，谁人都可以，哪会怕有一天只你共我。"


class MimoConfigError(Exception):
    """Raised when a MiMo call cannot start because configuration is missing."""


def mask_key(key: str) -> str:
    key = key or ""
    if not key:
        return ""
    if len(key) > 8:
        return key[:4] + "****" + key[-4:]
    return "****"


def require_key(key: str) -> str:
    text = (key or "").strip()
    if not text:
        raise MimoConfigError(_MISSING_KEY)
    return text


def resolve_key(settings: dict) -> str:
    return (settings.get("mimo_api_key") or "").strip()


def save_key(settings: dict, key: str) -> str:
    settings["mimo_api_key"] = (key or "").strip()
    return mask_key(settings["mimo_api_key"])


def public_view(settings: dict) -> dict:
    out = dict(settings)
    key = out.pop("mimo_api_key", "") or ""
    out["mimo_api_key_masked"] = mask_key(key)
    return out
```
