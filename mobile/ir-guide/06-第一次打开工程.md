# 第一次打开工程

← [[首页]] · 准备清单 [[03-你需要准备什么]]

## 1. 打开正确的目录

Android Studio → **Open** → 选：

```text
c:\jarvis\mobile\ir-android
```

成功的标志：左边是 Android 视图，能看到 `app` 模块，右下角开始 **Gradle Sync**。

失败的标志：打开后像一堆无关文件夹、没有绿色 Run 的 `app` 配置 → 你可能打开了 `c:\jarvis`。关掉，按上面的路径重开。

## 2. 等 Sync 结束

第一次会下载 Gradle 8.13 和一堆依赖，**10–20 分钟都正常**，别中断。

- 底部状态栏不再转圈
- Build 窗口没有红色失败

若提示 JDK：Settings → Build → Gradle → **Gradle JDK** 选 **17 或 21**（你已设 21 就可以留着）。

> [!info] 两个「Java 版本」不是一回事
> Studio 的 Gradle JDK = 用哪套 JDK **跑编译器**（21 没问题）。
> `app/build.gradle.kts` 里的 `JavaVersion.VERSION_17` / `jvmTarget = "17"` = APK **字节码**（保持 17，不用跟着改成 21）。
> NDK 的 `-std=c++17` 是 C++，也和这次设置无关。

若提示 NDK / CMake：SDK Manager 装 [[03-你需要准备什么]] 里写的版本。

## 3. 先不要点模拟器 Run

Sync 完后，顶部设备栏可能已经是 Pixel / `sdk_gphone16k_x86_64`。**先别按绿色按钮**，那个机会闪退。原因 [[10-为什么模拟器不行]]。

电脑上能立刻做的：跑单测 [[08-如何测试-电脑单测]]。

有华为真机：去 [[09-如何测试-华为真机]]。

## 4. 确认关键文件在不在

在 Studio 的 Project 视图打开这些（没有的话 App 在真机上会缺模型或用测试词典）：

| 文件 | 没有会怎样 |
|---|---|
| `app/src/main/jniLibs/arm64-v8a/libcactus.so` | 点「词」或「句」时模型打不开 |
| `app/src/main/assets/ecdict.db` | 词典卡片没有词条 |
| `app/src/main/assets/lemma.en.txt` | `sat` 这类变形查不到原形 |
| `app/src/main/assets/ecdict.db` | 词典空 |
| `app/src/main/assets/lemma.en.txt` | 词形还原弱，过去式可能查不到 |

缺文件怎么补 → [[12-资源文件从哪来]]。
