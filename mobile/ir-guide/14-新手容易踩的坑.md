# 新手容易踩的坑

← [[首页]]

这些是手机开发入门时几乎每人踩一次、和这个项目叠在一起更明显的点。

## 1. 打开了 Jarvis 根目录

`c:\jarvis` 很大，里面还有 Python、文档。Android Studio 要的是 **`mobile\ir-android`**。

## 2. USB 线只充电

超市线经常没有数据线芯。现象：充电图标有，Studio 设备栏没有手机。换原装或标明「数据线」的。

## 3. 华为少开了一个开关

除了 USB 调试，还有 **仅充电模式下允许 ADB 调试**。只开第一个，插上仍是 `unauthorized` 或看不见。

## 4. 模拟器开着，一按 Run 就装到模拟器

设备下拉框要养成习惯：**先看名字再点绿色按钮**。有 `sdk_gphone` / `Medium Phone` / `Pixel` 且没插真机时，不要 Run 这个 App。

## 5. 以为「未收录」是程序坏了

3 词测试库 + 词形还原失败都会这样。先点范文里的 `bank` 对照 [[05-选词如何工作]]。

## 6. 把 45MB 模型和完整词典提交到 git

不要 `git add` `ecdict.db`、`lemma.en.txt`、`libcactus.so`，也不要提交 `app/.cxx/` 和 `app/build/`。已经 gitignore。

## 7. 用应用市场安装包的思维等「上架」

开发阶段用的是 **debug APK**，只通过 USB / Studio 安装。不会出现在华为应用市场。卸载：手机设置 → 应用 → Y。

## 8. 手机锁屏、换 USB 口、Hub

adb 会断。现象：刚才还在，Run 突然 No target device。解锁、拔插、点允许。

## 9. 第一次 Sync 当成卡死

Gradle 下载可以非常安静。看右下角状态和 `Build` 窗口，不要反复 Cancel。

## 10. 在 Windows 上找 iOS 模拟器

没有。苹果那条线要 Mac。见 [[15-iOS以后要什么]]。

## 11. 扫描件 PDF

PDF 导入走文本抽取，不是 OCR。图片书会得到空字符串，界面像没打开。

## 12. 16KB 模拟器「能装上」就以为能跑

能 install 成功仍然会在启动时 UnsatisfiedLinkError。以 Logcat 为准，不以「安装成功」为准。
