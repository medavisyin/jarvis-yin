# 资源文件从哪来

← [[首页]] · 结构 [[04-项目结构]]

模型和完整词典 **不进 git**（太大、也不该提交）。工程里有一份说明：

`mobile/ir-android/scripts/fetch-assets.md`

下面是新手版。

## 本机要放的文件

| 文件 | 放到 | 大概体积 |
|---|---|---|
| `libcactus.so` | `app/src/main/jniLibs/arm64-v8a/libcactus.so` | 约 2MB，Qwen 运行时，不进 git |
| `ecdict.db` | `app/src/main/assets/ecdict.db` | ECDICT 精简库（word/pos/translation），不进 git |
| `lemma.en.txt` | `app/src/main/assets/lemma.en.txt` | 词形表，不进 git |

Qwen 的权重不放这里。在手机的设置里下载，进应用私有目录 `files/models/`。手机上没有 Ollama。权重由安装包里的 `libcactus.so` 在 Y 自己的进程里读进内存，见 [[17-Qwen怎么用]]。

细节表在 `mobile/ir-android/scripts/fetch-assets.md`。

> [!warning] 不要提交这些文件
> `.gitignore` 已忽略 `ecdict.db`、`lemma.en.txt`、`jniLibs/` 和 `app/.cxx/`。`git status` 里不应看到它们。

## 词典

- **现在**：`assets/ecdict.db` 是 ECDICT 1.0.28 精简库（约 337 万条，只留 word / pos / translation）。官方原 sqlite 解压约 812MB，没有打进 APK。
- 手机上如果以前装过 3 词测试库，重新 Run 一次即可；代码会按文件大小重拷。

表结构必须是 ECDICT 的 `stardict`（代码在 `dict/StarDictSql.kt`）。乱放一个别的 sqlite 会查不到词。卡片只留下你选中的原文。
