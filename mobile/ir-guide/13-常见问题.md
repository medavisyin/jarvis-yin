# 常见问题

## Studio 相关

**Q. 打开工程后没有绿色 Run / 没有 app 模块？**  
开错目录了。必须是 `c:\jarvis\mobile\ir-android`。见 [[06-第一次打开工程]]。

**Q. Sync 一直失败，说 JDK？**  
Settings → Build → Gradle → Gradle JDK 选 **17 或 21**。本工程 APK 字节码仍是 17，不必把 `build.gradle.kts` 改成 21。

**Q. Studio 里 Java 设成了 21，要不要改工程？**  
不用。Gradle JDK 21 + `jvmTarget 17` 是正常组合。不要去改 C++ 的 `-std=c++17`。

**Q. 跑 WordSelectorTest 报 `NoClassDefFoundError: WordSelector`？**  
测的是能跑的，但你点的是 IntelliJ JUnit 启动器，classpath 里只有测试 class、没有主代码。改成 Gradle 跑，见 [[08-如何测试-电脑单测]]。

**Q. 点词后词典有了，但没有「这句里的意思」？**  
那一行由 Qwen 写。设置里先下载模型（0.6 约 575MB，1.7 约 810MB，手机要能上网）。卡片上先出词典，模型写完才出现中文。之后离线可用。

**Q. 点 bank 闪退？**  
再闪退把 Logcat 里 `AndroidRuntime` 发过来。过滤标签是 `Y`。

**Q. CMake / NDK 报错？**  
安装 NDK `27.2.12479018` 和 CMake `3.22.1`。见 [[03-你需要准备什么]]。

**Q. `compileSdk 36` 警告？**  
警告，不是失败。见 [[07-如何Build]]。

## 设备相关

**Q. 顶部只有 Pixel 10a / API 37+？**  
那是模拟器列表。不要用它测这个 App。插华为，列表里才会出现真机。见 [[10-为什么模拟器不行]]。

**Q. 点 Run 立刻闪退？**  
若设备是 `…x86_64` 或名字带 16k：就是模拟器页对齐问题。换真机。

**Q. `INSTALL_FAILED_NO_MATCHING_ABIS`？**  
当前设备不接受 `arm64-v8a` only 的包（典型是老 x86 模拟器）。

**Q. adb devices 空的 / unauthorized？**  
手机弹出「允许 USB 调试」点允许；华为打开「仅充电模式下允许 ADB」；USB 改 MTP；换线。

**Q. 电脑找不到华为？**  
装 HiSuite / 华为 USB 驱动。见 [[09-如何测试-华为真机]]。

## App 行为

**Q. 好多词都「未收录」？**  
完整 ECDICT 已打进 APK。若仍大量「未收录」，先在 Studio 对华为再 Run 一次，让新词典覆盖手机上的旧 3 词库。生僻词、专名本来就可能没有。

**Q. 卡片上「不确定」？**  
卡片把词典里的几条释义都列出来。Qwen 那一行才是按这句话写的中文。

**Q. Logcat 有 `using fake`？**  
查 `jniLibs/arm64-v8a/libcactus.so` 在不在，以及设置里的模型有没有下完。见 [[11-Logcat怎么看]]、[[12-资源文件从哪来]]。

**Q. 打开 PDF 没变化？**  
扫描版 PDF 没有文字层，抽出来是空的。先用带可选中文字的 PDF，或 TXT。
