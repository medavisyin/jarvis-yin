# 如何测试：华为真机

← [[首页]] · 这是在手机上试 Qwen 的路径

模拟器为什么不行 → [[10-为什么模拟器不行]]。苹果不行 → [[15-iOS以后要什么]]。

## 一、手机设置（做一次）

1. **设置 → 关于手机**，连点「版本号」约 7 次，直到提示已是开发者。
2. 回到设置，打开 **开发者选项**（有的机在系统和更新里）。
3. 打开：
   - **USB 调试**
   - **仅充电模式下允许 ADB 调试**（华为特有，经常漏）
4. 用 **能传文件的 USB 线** 连电脑，弹窗点 **允许**（勾选「始终允许这台电脑」）。
5. 通知栏 USB 用途选 **传输文件（MTP）**，不要停在「仅充电」。

> [!tip] 纯血鸿蒙
> 关于手机里如果完全没有 Android 版本、应用市场只上鸿蒙应用，这个 APK 装不了。EMUI / 带 Android 兼容的 HarmonyOS 才可以。

## 二、Studio 里看到手机

1. 关掉正在跑的 Pixel 模拟器（Device Manager → Stop）。否则容易点错设备。
2. 顶部设备下拉里应出现华为机型，不要选 `Medium Phone` / `sdk_gphone…`。
3. 配置选 **app**，点绿色 **Run**（Shift+F10）。

安装包里有词典，体积不小，要等。

手机桌面出现 **Y**。若没有：看 Studio 的 Build / Run 窗口红色错误，或 [[13-常见问题]]。

## 三、进 App 后测什么

范文：`They sat on the river bank.`

| 步骤 | 期望 |
|---|---|
| 长按一个词，点「词」 | 词典词条，下面一行中文 |
| 点「句」 | 同一词条，下面是整句中文译文 |
| 设置里打开 TXT / EPUB / PDF | 正文换成文件，左右滑翻页，书架能再打开 |
| Logcat 过滤 `Y` | 导入失败会打 `import failed` |

## 四、用 Logcat 看导入和崩溃

步骤 → [[11-Logcat怎么看]]。模型打不开时，卡片上会写「模型打不开。文件还在，不用重新下载。」

## 五、命令行确认（可选）

PowerShell：

```bat
"%LOCALAPPDATA%\Android\Sdk\platform-tools\adb.exe" devices
"%LOCALAPPDATA%\Android\Sdk\platform-tools\adb.exe" shell getprop ro.product.cpu.abi
```

- `devices` 里你的手机是 `device` 状态（不是 `unauthorized`）
- ABI 应是 `arm64-v8a`

## 六、没电脑驱动时

Windows 可能不认华为。可装 [HiSuite](https://consumer.huawei.com/cn/support/hisuite/) 或华为 USB 驱动，再拔插数据线。设备管理器里若是未知设备，就是驱动问题。
