# 你需要准备什么

← [[首页]] · 术语见 [[02-术语表]]

## 电脑（你已经有了）

- Windows 10/11
- **Android Studio**（能打开 `ir-android` 即可）
- 磁盘：工程 + Gradle 缓存 + SDK，预留至少 **10GB**
- 网络：第一次 Sync / 下 NDK 会很慢；Hugging Face 在国内常超时，模型要用镜像（见 [[12-资源文件从哪来]]）

- **JDK 17 或 21**（Android Studio 自带即可；Gradle JDK 设 21 不用改工程）

不需要：

- 会写 Android
- Linux
- 付费 Google 账号
- 把工程的 `jvmTarget` 改成 21

## 手机（跑 Qwen 需要真机）

- **华为 ARM64 可以**（Mate / P / nova 等麒麟或骁龙）
- 系统要能装 Android APK（EMUI，或带 Android 兼容的 HarmonyOS）
- **纯血鸿蒙 HarmonyOS NEXT 不行**（没有 Android 兼容层）
- Android 8.0 及以上（工程 `minSdk 26`）
- 一条 **能传数据的 USB 线**（很多「充电线」不行）

怎么开调试 → [[09-如何测试-华为真机]]。

## 不需要、也别指望的

| 东西 | 原因 |
|---|---|
| Pixel 模拟器 / API 37+ 虚拟机 | [[10-为什么模拟器不行]] |
| iPhone | 装不了 APK，见 [[15-iOS以后要什么]] |
| Jarvis 后端、Ollama | 这个 App 完全离线 |

## Studio 里建议装上的 SDK 组件

打开 SDK Manager（三个点或 Tools → SDK Manager）：

- Android SDK Platform（API 34 或更高，工程 compileSdk 是 36）
- **NDK 27.2.12479018**（工程写死了这个版本）
- **CMake 3.22.1**
- SDK Platform-Tools（里面有 adb）

缺 NDK 时，点 Run 会在 C++ 那一步失败，Kotlin 界面代码其实没问题。
