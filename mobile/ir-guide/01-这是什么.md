# 这是什么

← [[首页]]

## 一句话

这是一个不依赖 Jarvis 服务器的 Android 精读应用：在手机上打开一篇英文，点一个单词，弹出卡片。词条来自 **ECDICT**。一句中文释义或整句翻译来自手机上的 **Qwen3**。

桌面上的应用名是 `Y`，包名是 `com.jarvis.ir`。Qwen 怎么被调用，见 [[17-Qwen怎么用]]。

## 它做什么

- 长按选一个词，再点另一个词可以拉成一片；双击正文取消
- 词旁边有「词」「句」，手机有英文语音时还有「读」
- 「打开 TXT / EPUB / PDF」在设置里。读过的书在书架上，左右滑翻页
- 词典是 **ECDICT**（英汉）。词条本身不由模型编造
- **Qwen3**（0.6B 或 1.7B）在手机上写一句语境释义，或翻译整句。见 [[17-Qwen怎么用]]

## 它明确不做

这些仍不做：

- 整章长文讲解、口语练习、笔记
- 把句子发到网上的大模型
- 微信小程序 / 网页版

> [!warning] 两套模型不要混
> ECDICT 负责词条。Qwen 负责那一句中文（词的语境，或整句译文）。词典没有这个词时，卡片只保留你选中的原文，不再写「未收录」。

## 电脑和手机怎么分工

| 在哪 | 干什么 |
|---|---|
| Windows + Android Studio | 打开工程、编译、把 APK 装到手机 |
| 电脑上的 Gradle 单测 | 测词典解析、切段、PDF/EPUB。不跑 Qwen |
| ARM64 安卓真机（华为可以） | 跑 Qwen、点词、看卡片 |

Studio 模拟器为什么不行 → [[10-为什么模拟器不行]]。

## 现在做到哪一步

华为真机可以装调试包。词典是完整 ECDICT 精简库（word / pos / translation）。Qwen 权重要在设置里单独下载，见 [[17-Qwen怎么用]]。
