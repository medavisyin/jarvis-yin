# 术语表

← [[首页]]

遇到陌生词先到这里。不必一次背完。

## 安装与运行

| 词 | 意思 |
|---|---|
| **APK** | Android 的安装包，类似 Windows 的 `.exe` / `.msi`。编出来一般在 `app/build/outputs/apk/debug/app-debug.apk`。 |
| **包名 / applicationId** | 系统用来区分 App 的身份证。本项目是 `com.jarvis.ir`。 |
| **adb** | Android Debug Bridge，电脑和手机对话的命令行。Studio 内部也在用它装包、看日志。 |
| **USB 调试** | 手机允许电脑用 adb 安装应用、读日志。必须打开，否则 Studio 看不到手机。 |
| **Logcat** | 手机上所有程序打出来的日志。过滤 `Y` 看本 App。见 [[11-Logcat怎么看]]。 |

## 芯片与兼容

| 词 | 意思 |
|---|---|
| **ABI** | CPU 指令集。手机常见 `arm64-v8a`；Windows 模拟器常见 `x86_64`。 |
| **arm64-v8a** | 64 位 ARM。华为麒麟、骁龙、大部分安卓真机都是这个。本 App 的 `libcactus.so` 只有这一份。 |
| **x86_64** | Intel/AMD PC 的指令集。Studio 默认模拟器是这个。本 App 没有 x86 的 Qwen 引擎。 |
| **16 KB 页 / ps16k** | 新系统镜像用 16KB 内存页。本 App 的 `.so` 按 4KB 对齐，装上去会闪退。 |

## 编译工具

| 词 | 意思 |
|---|---|
| **Gradle** | Android 的构建系统。点绿按钮其实就是在跑 Gradle。 |
| **AGP** | Android Gradle Plugin，Gradle 里负责 Android 那一层。本项目 8.8.2。 |
| **Gradle JDK** | 跑 Gradle / Android Studio 编译进程的 JDK。**17 或 21 都可以**（本机已用 21 就不用改回去）。不要用 8。 |
| **jvmTarget / Java 17** | 打进 APK 的字节码版本。工程里写死 `VERSION_17` / `jvmTarget = "17"`。**不必改成 21**，和 Studio 选 21 不冲突：JDK 21 可以编出 Java 17 字节码。 |
| **C++17** | 以前编本地库时用过。现在工程里没有 C++ 源码，Qwen 运行时是现成的 `libcactus.so`。 |
| **Sync** | Studio 根据 `build.gradle.kts` 下载依赖、配工程。第一次可能十几分钟。 |
| **assembleDebug** | 打出可调试的 APK，不经过应用商店签名那套。 |

## Native（C/C++）层

| 词 | 意思 |
|---|---|
| **NDK** | 编 C/C++ 用的工具包。本工程不再编 C++，一般不用单独配。 |
| **JNI** | Java/Kotlin 调用本地库。Qwen 通过 `System.loadLibrary("cactus")` 加载 `libcactus.so`。 |
| **`.so`** | 打进 APK 的本地库。`libcactus.so` 放在 `jniLibs/arm64-v8a/`，不进 git。 |
| **abiFilters** | 工程里写死只打 `arm64-v8a`，所以 x86 模拟器对不上。 |

## 本 App 专有

| 词 | 意思 |
|---|---|
| **Qwen3** | 手机上的中文模型。设置里选 `qwen3-0.6` 或 `qwen3-1.7`。权重首次下载，不进 APK，也不进 git。见 [[17-Qwen怎么用]]。 |
| **ECDICT** | 开源英汉字典。本 App 用 sqlite 表 `stardict`。文件 `ecdict.db` 不进 git。 |
| **lemma** | 词形还原：`sat` → `sit`，`banks` → `bank`。文件 `lemma.en.txt`，不进 git。 |
| **Compose** | Android 现代 UI 写法。`ReaderScreen.kt` 是阅读界面。 |
