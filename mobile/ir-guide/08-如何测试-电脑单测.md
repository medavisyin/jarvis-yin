# 如何测试：电脑单测

← [[首页]] · 先会 Build [[07-如何Build]]

单测跑在 **电脑的 JVM** 上，不装 APK、不跑 Qwen、不需要手机。用来确认：词典切义项、词形还原、TXT/EPUB/PDF 抽文本、切段、书架记录。

## 在 Studio 里跑

### 跑全部

1. 右边 **Gradle** 面板
2. `ir-android` → `app` → `Tasks` → `verification`
3. 双击 **`testDebugUnitTest`**

底部 Run 窗口应看到绿色勾。

### 跑某一个

**不要点类名左边那个绿色三角（JUnit）**，Android 工程里它经常只把测试 class 放进 classpath，主代码 `WordSelector` 找不到，报：

```text
java.lang.NoClassDefFoundError: com/jarvis/ir/ui/WordSelector
ClassNotFoundException: com.jarvis.ir.ui.WordSelector
```

命令行里若出现 `com.intellij.rt.junit.JUnitStarter` 和 `android-36\android.jar`，就是这条错误路径。

正确做法任选其一：

1. **改成用 Gradle 跑测试（推荐改一次就好）**  
   Settings → Build, Execution, Deployment → Build Tools → Gradle → **Run tests using: Gradle**  
   然后把 Run 配置里旧的 `WordSelectorTest` 删掉，再跑。
2. **Gradle 面板** → `app` → `Tasks` → `verification` → `testDebugUnitTest`
3. **命令行**（只跑这一个类）：

```bat
cd c:\jarvis\mobile\ir-android
.\gradlew.bat :app:testDebugUnitTest --tests com.jarvis.ir.ui.WordSelectorTest
```

成功应是 `BUILD SUCCESSFUL`。这个测试是纯 Kotlin，不需要手机，也不跑 Qwen。

## 命令行

```bat
cd c:\jarvis\mobile\ir-android
.\gradlew.bat :app:testDebugUnitTest
```

> [!warning] 不要用 `gradlew test --tests 类名` 那种桌面 Java 写法
> Android 工程要用 `:app:testDebugUnitTest`，再加 `--tests`。

## 这些测试覆盖什么

| 测试类 | 在验证 |
|---|---|
| `SenseParserTest` | ECDICT 释义字符串切成义项 |
| `LemmaMapTest` | `sat` → `sit` 这类还原 |
| `DictionaryRepositoryTest` | 查词逻辑 |
| `ExplainPipelineTest` | 词典卡片列出释义；没有的词只保留选中的原文 |
| `GlossPromptTest` / `GlossTextTest` | 翻译提示把「中文：」放在最后，并丢掉英文改写 |
| `WordSelectorTest` | 点坐标对应哪个词、哪句 |
| `ChunkerTest` / `TxtImporterTest` | 切段 |
| `EpubImporterTest` / `PdfImporterTest` | 用 `src/test/resources` 里的小 fixture |

它们不能证明手机上 Qwen 写得准。那要 [[09-如何测试-华为真机]]。
